# 中断

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-15 完成（含补练，总线与 I/O ③/③）

## 定义
中断 = CPU 暂停当前工作去处理事件，处理完回来继续。好处：不必轮询等事件、能处理异常、多事件按优先级协调。

## 要点（含案例）

### 中断向量 / 向量表
- 每个中断源对应一段**中断服务程序（ISR）**。
- **中断向量 = 中断服务程序的入口地址**。
- **中断向量表**：中断号 → 服务程序入口地址的映射表。CPU 收到中断，用中断号查表得入口，跳过去执行。
- 类比：向量表=电话簿，中断号=人名，中断向量=电话号码（入口）。

### 中断响应过程（顺序常考）
```
1. 关中断   (防响应过程中又被新中断打断)
2. 保存现场 (断点 PC、状态 PSW、寄存器压栈)
3. 取中断向量 (查表得服务程序入口)
4. 执行中断服务程序 (处理事件)
5. 恢复现场 (从栈恢复 PC/PSW/寄存器)
6. 开中断 + 返回 (回到断点继续)
```
口诀：**关→存→取→执→复→开返**。关/开配对，存/复配对。

### 中断优先级 / 嵌套
- **高优先级可打断低优先级**（中断嵌套）；同级或低级不能打断高级。
- 嵌套：A(低)处理中 → B(高)来 → 暂停 A 处理 B → B 完回 A → A 完回主程序。
- 屏蔽：可屏蔽中断能被 CPU 屏蔽（关中断时不响应）；不可屏蔽中断必须响应。

### 内部中断 vs 外部中断
| 类型 | 来源 | 同步/异步 | 例子 |
| --- | --- | --- | --- |
| **内部中断（异常/陷阱）** | CPU 内部 | 同步（指令执行触发） | 除零、溢出、缺页、系统调用 trap |
| **外部中断（硬件中断）** | 外部设备 | 异步（随机来） | I/O 完成、定时器、电源故障 |

外部细分：
- **可屏蔽中断（INTR）**：CPU 可屏蔽，如一般 I/O。
- **不可屏蔽中断（NMI）**：必须响应，如电源故障、内存校验错。

## 易错点
1. **中断向量 = 服务程序入口地址**（不是中断号、不是数据）。
2. 响应顺序：**关→存→取→执→复→开返**。关/开、存/复配对。
3. 高优先级可打断低优先级（嵌套）；同级/低级不能打断高级。
4. 内部中断**同步**（指令触发）；外部中断**异步**（外部随机来）。
5. 可屏蔽中断能屏蔽；不可屏蔽（电源故障）必须响应。
6. 保存现场含 PC（断点）+ PSW（状态）+ 寄存器。
7. 内部例：除零/缺页/系统调用；外部例：I/O 完成定时器/电源故障。

## 真题考法（上午单选）
- "中断向量是"→ 服务程序入口地址。
- 响应过程排序。
- "高优先级能否打断低优先级"→ 能（嵌套）。
- 内部 vs 外部中断归类。
- 可屏蔽 vs 不可屏蔽。

  理: 向量表=电话簿，中断号→入口地址
- [#N55] 口诀 ｜ 响应过程：关→存→取→执→复→开返（关/开、存/复配对）
  理: 关中断最先（防打断）；保存现场含 PC+PSW+寄存器
- [#N56] 判据 ｜ 高优先级可打断低优先级（嵌套）；同级/低不能打断高
  例: A(低)处理中→B(高)打断→B 完回 A→A 完回主程序
- [#N57] 判据 ｜ 内部中断 = CPU 自己产生（同步：除零/缺页/trap）；外部中断 = 外部设备产生（异步：I/O/定时器/电源）
  理: 内部是执行指令触发；外部是设备随机发信号
- [#N58] 判据 ｜ 可屏蔽 vs 不可屏蔽（电源故障=不可屏蔽 NMI）
  例: 可屏蔽=一般 I/O（INTR）；不可屏蔽=电源故障/内存校验错（NMI）
- [#N59] 判据 ｜ 保存现场 = PC（断点）+ PSW（状态）+ 寄存器
  理: 断点 PC 让中断完能回来；PSW 恢复状态；寄存器恢复数据
