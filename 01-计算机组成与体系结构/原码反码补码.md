# 原码 / 反码 / 补码（含移码）

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-06 完成

## 定义
- 机器数 = 符号位（0 正 / 1 负）+ 数值位；真值 = 机器数代表的实际数值。
- 同一真值有三种机器码：原码、反码、补码（+移码）。区别全在「负数怎么编码」。

## 要点（含案例）

### 三码定义（8 位，真值 −5 一路推到底）
| 码 | 规则 | −5 编码 |
| --- | --- | --- |
| 原码 | 符号位 + 绝对值 | `1 0000101` |
| 反码 | 正=原码；负=符号1 + 数值位取反 | `1 1111010` |
| 补码 | 正=原码；负=反码 +1 | `1 1111011` |
| 移码 | 补码符号位取反 | `0 1111011` |

推演：原码 `1 0000101` → 数值位取反 → 反码 `1 1111010` → +1 → 补码 `1 1111011` → 符号位取反 → 移码 `0 1111011`。

### 互转规则（核心）
- 正数三码相同；只有负数才转换。
- 原码↔反码：数值位取反。
- 反码↔补码：+1（反向 −1）。
- **自逆性**：补码变换 `f(x) = 2^k − x`（k 位数值位），`f(f(x)) = x`，所以 `f = f⁻¹`。原码↔补码两个方向都是「取反+1」（等价于「−1 再取反」，因为 `NOT(x)+1 = NOT(x−1) = 2^k − x`）。
- 速算：符号位不动，从最低位起找到第一个 1，它及以下保留、以上数值位取反。

### 由补码求真值（高频）
- 符号 0 → 正，数值位直读。
- 符号 1 → 负，数值位取反 +1 得绝对值，添负号。
- 例 补码 `11100110`：数值位 `1100110` 取反 `0011001` +1 = `0011010` = 26 → **−26**。
- −128 边界：补码 `10000000`，数值位 `0000000` 取反 `1111111` +1 = `10000000` = 128 → **−128**（「−1 取反」法在此失效，因数值位为 0 时 −1 下溢）。

### 范围与 0 的表示
- n 位补码：`−2^(n−1) ~ 2^(n−1)−1`；8 位 → **−128 ~ +127**。
- 原码/反码：`−(2^(n−1)−1) ~ +(2^(n−1)−1)`；8 位 → −127 ~ +127，且有 ±0。
- 0 的码点：原码 2 个（`00000000`/`10000000`）、反码 2 个（`00000000`/`11111111`）、补码 1 个（`00000000`）。
- **+1 解放 −0**：反码 −0 `11111111` +1 = `100000000` 丢进位 → `00000000`，−0 塌缩进 +0；腾出的 `10000000` 被补码读作 −128。这是补码比原码多一个码点（−128）的根源。

## 易错点
1. 正数三码相同，别对正数「取反+1」（+5 补码仍是 `00000101`）。
2. 8 位补码 `10000000` = **−128**（不是 −0、不是 +128）；原码 `10000000` = −0、反码 `10000000` = −127。
3. 0 在补码唯一；原码/反码有 ±0。
4. 由补码求真值：负数取反后是 **+1**（不是 −1）。
5. 移码 = **补码**符号位取反，不是原码符号位取反。
6. 「−1 取反」法等价于「取反+1」，但对数值位=0（最小负数）失效，因 −1 下溢。

## 真题考法（上午单选）
- 给真值求补码/移码十六进制：−50 → `50=00110010` → 取反 `11001101` → +1 → `11001110` = **CEH**。
- 给补码求真值：`11100110` → −26。
- 范围题：n 位补码/原码各自范围；`10000000` 在补码下 = −128。
- 概念题：0 的表示、补码为何比原码多一个码点。
