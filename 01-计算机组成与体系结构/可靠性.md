# 可靠性

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-15 完成

## 定义
可靠性 = 衡量系统"多能扛故障"和"多快修好"。核心指标：MTBF/MTTR + 串/并联可靠度。

## 要点（含案例）

### MTBF / MTTR / 可用度
- **MTBF（平均无故障时间）**：两次故障间平均时间。越大越可靠。
- **MTTR（平均修复时间）**：故障后修好平均时间。越小越好修。
- **可用度 A = MTBF / (MTBF + MTTR)**：系统正常占总时间比例，→1 最优。

### 串联 / 并联可靠度
**串联**（全正常系统才正常）：
- R = R₁ × R₂ × … × Rₙ
- 越多越不可靠；一个坏全坏。

**并联**（一个正常系统就正常，冗余）：
- R = 1 − (1−R₁)(1−R₂)…(1−Rₙ)
- 越多越可靠；全坏才坏。
- 两部件特例：R = R₁ + R₂ − R₁R₂。

### worked case
- 串联：0.9 × 0.8 × 0.7 = 0.504
- 并联（两件 0.9/0.8）：1 − 0.1×0.2 = 0.98
- 混联：并联子块（0.9∥0.9）= 1−0.1²=0.99，再串联 0.8 → 0.99×0.8 = 0.792
- 可用度：MTBF=1000, MTTR=100 → A=1000/1100≈0.91

## 易错点
1. 串联乘、并联用"1 减各不可靠度之积"。
2. 串联越多越不可靠；并联越多越可靠。
3. MTBF 大→可靠；MTTR 小→好修；A = MTBF/(MTBF+MTTR)。
4. 并联是冗余备份，全坏才坏。
5. 混联：先算并联子块，再按串联乘起来。
6. 串联：一个坏全坏；并联：全坏才坏。

## 真题考法（上午单选）
- 给各部件 R，求串联/并联/混联系统可靠度。
- 给 MTBF、MTTR，求可用度 A。
- 串联 N 个 R=0.9 → 0.9ⁿ；并联 2 个 R=0.9 → 1−0.1²=0.99。

## 我的笔记
- [#N60] 判据 ｜ MTBF 越大越可靠，MTTR 越小越好修
  理: MTBF=两次故障间隔；MTTR=修复时间
- [#N61] 口诀 ｜ A = MTBF / (MTBF + MTTR)
  理: 可用度=正常时间占总时间比例
- [#N62] 判据 ｜ 串联乘：R = R₁×R₂×…×Rₙ（越多越不可靠；一个坏全坏）
  例: 0.9×0.8×0.7=0.504
- [#N63] 判据 ｜ 并联 = 1 − 各(1−Rᵢ) 之积（冗余越多越可靠；全坏才坏）
  例: 0.9∥0.8 → 1−0.1×0.2=0.98
- [#N64] 口诀 ｜ 混联：先算并联子块，再按串联乘起来
  例: (0.9∥0.9)→0.99，再串联 0.8 → 0.792
