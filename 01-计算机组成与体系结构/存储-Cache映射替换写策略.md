# Cache 映射 + 替换 + 写策略

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-09 完成（含补练，存储 ②/③）

## 定义
- 地址映射：主存块放 Cache 哪个位置——直接 / 全相联 / 组相联。
- 替换算法：Cache 满 / 冲突时换谁出去。
- 写策略：写命中 / 缺失时主存要不要同步。

## 要点（含案例）

### 三种映射
| 映射 | 块能放哪 | 地址有无 index | 查找 | 特点 |
| --- | --- | --- | --- | --- |
| 直接 | 固定行（j mod N） | 有（定行） | 只比固定行 | 简单/快/冲突高 |
| 全相联 | 任意行 | 无 | 比所有行 | 灵活/命中高/查找慢 |
| 组相联 | 固定组+组内任意 | 有（定组） | 比组内行 | 折中 |

worked case（Cache 8 行）：直接映射块 `0,8,16`→行 0（冲突）；2 路组相联（4 组）块 `0,4,8`→组 0 组内 2 行任选；全相联任意行。

**全相联三大特征（绑一起）**：能放任意行 ⟺ 无 index ⟺ 查所有行。
**k 路组相联**：k=1 退化为直接；k=全部行数退化为全相联。

### 替换算法
| 算法 | 规则 | 特点 |
| --- | --- | --- |
| LRU | 换最久没访问的 | 实用最优、最常用 |
| FIFO | 换最早调入的 | 简单、可能换掉常用的 |
| LFU | 换使用次数最少的 | — |
| RAND | 随机 | 简单/不稳 |
| OPT | 换未来最远才用的 | 理论最优、不可实现（基准） |

### 写策略
**写命中**：写回（只写 Cache，脏位标记，替换时写回主存）；全写（同时写 Cache + 主存）。
**写缺失**：写分配（调入 Cache 再写）；不按写分配（直接写主存）。
**搭配**：写回 + 写分配（都留 Cache）；全写 + 不按写分配（都动主存）。

## 易错点
1. 冲突率：直接最高、全相联最低、组相联居中。
2. 全相联查所有行；直接只比固定行。
3. 全相联**无 index**；直接/组相联有 index。
4. k 路组相联：k=1 退化直接、k=全部退化全相联。
5. LRU 实用最优、OPT 理论不可实现——别混。
6. 写回用脏位；全写不用。
7. 搭配：写回 + 写分配、全写 + 不按写分配。
8. 组相联是固定组 + 组内任意，**不是任意行**（任意行是全相联）。

## 真题考法（上午单选）
- 冲突率最高/最低、全相联查什么、地址字段有无 index。
- LRU/OPT 哪个最优/可实现。
- 写回用什么标记、搭配判别。

## 我的笔记
- [#N32] 口诀 ｜ 三种映射：全相联=任意行/无 index/查所有行；直接=固定行/有 index/查一行；组相联=固定组+组内任意/有 index 定组
  理: 全相联全自由、直接全固定、组相联半自由
- [#N33] 判据 ｜ "能放任意行 ⟺ 无 index ⟺ 查所有行"（全相联三大特征，绑一起）
  例: 全相联无 index 是因为无需指定位置
- [#N34] 判据 ｜ 写策略搭配：写回+写分配（都留 Cache）；全写+不按写分配（都动主存）
  理: 写回倾向留 Cache→配写分配；全写每次访主存→调入无意义→配不按写分配
- [#N35] 判据 ｜ 写回用脏位，全写不用
  理: 写回延迟同步→需脏位标记改过；全写立即同步→无脏数据
- [#N36] 判据 ｜ LRU 实用最优 / OPT 理论不可实现
  例: OPT 换未来最远才用的，需预知未来→不可实现，作基准
