# 存储层次 + 局部性 + Cache 命中率/AMAT

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-08 完成（存储 ①/③）

## 定义
- 存储层次：多层叠加，越上越小越快越贵、越下越大越慢越便宜；上层存热点、下层存全量。
- 局部性原理：程序访问内存不均匀，有时间/空间局部性，是 Cache/虚拟存储能 work 的根本前提。
- Cache 命中率/AMAT：衡量 Cache 性能的指标。

## 要点（含案例）

### 存储层次
| 层次 | 介质 | 速度 | 容量 | 成本 |
| --- | --- | --- | --- | --- |
| 寄存器 | CPU 内 | 最快 | KB | 最贵 |
| Cache（L1/L2/L3） | SRAM | 几 ns | KB~MB | 贵 |
| 主存 | DRAM | 几十 ns | GB | 中 |
| 辅存 | 磁盘/SSD | μs~ms | TB | 便宜 |

### 局部性原理
- **时间局部性**：刚访问的数据短期可能再用（循环变量、热点）→ 保留上层。
- **空间局部性**：访问某地址短期可能访问邻近地址（数组、顺序指令）→ 按块调入上层。
```
for (i=0;i<1000;i++) sum += arr[i];   // arr 顺序→空间；sum 反复→时间
```

### Cache 命中率 + AMAT
- 命中 h = 命中数/总访问；缺失率 1−h。
- **AMAT = h×t_c + (1−h)×t_m**（t_c=Cache 时间，t_m=主存时间）
- worked case：t_c=10ns, t_m=100ns, h=0.95 → AMAT=0.95×10+0.05×100=9.5+5=**14.5ns**
- 等价：给 miss_penalty 时 AMAT = t_c + (1−h)×penalty（t_m=t_c+penalty 时互通）

## 易错点
1. AMAT = h×t_c + (1−h)×t_m：别把 (1−h) 写成 h，别把 t_c/t_m 搞反。
2. 命中率 h 与缺失率 1−h 别混。
3. 层次排序：上快小贵/下慢大便宜。
4. 时间局部性→保留上层；空间局部性→按块调入。别混。
5. 局部性是 Cache/虚拟存储能 work 的根本前提。
6. 公式口径：标准 `h×t_c+(1−h)×t_m`；给 penalty 用 `t_c+m×penalty`，别混。

## 真题考法（上午单选/计算）
- 给 t_c、t_m、h 求 AMAT；给 AMAT 反求 h。
- 时间/空间局部性判别。
- 层次结构速度/容量排序。
