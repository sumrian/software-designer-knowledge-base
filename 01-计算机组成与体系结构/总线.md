# 总线

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-15 完成（总线与 I/O ①/③）

## 定义
总线 = 一组公共连线，连接 CPU / 主存 / IO，分时共享通信。省连线、易扩展，但有争用、成瓶颈。

## 要点（含案例）

### 分类（按传输内容）
| 类型 | 内容 | 方向 | 特点 |
| --- | --- | --- | --- |
| 数据总线 DB | 数据 | 双向 | 宽度 = 一次传输位数 |
| 地址总线 AB | 地址 | 单向（CPU→） | 宽度 = 寻址能力（n 位 → 2ⁿ） |
| 控制总线 CB | 控制（读写/中断/时钟） | 双向混合 | 协调 |

### 宽度的意义
- 地址总线 32 位 → 2³² = 4GB（按字节编址）。
- 数据总线 32 位 → 一次传 4 字节。

### 总线复用
地址 / 数据线复用（先传地址再传数据），省引脚。需**锁存器**锁存地址（分时复用，地址要给内存保持）。例：8086 `AD0~AD15`。

### 总线带宽
> 带宽 = 宽度(字节) × 频率 × 每周期次数

worked case：64 位 = 8 字节，50MHz，每周期 1 次 → 8 × 50 = **400 MB/s**。

## 易错点
1. 数据总线定"宽"（一次多少位）；地址总线定"空间"（2ⁿ）。别反。
2. 地址单向、数据双向。
3. 地址总线 n 位 → 2ⁿ（不是 n）。
4. **位 ÷ 8 = 字节**（64 位 = 8 字节，不是 4）。
5. 带宽 = 宽度(字节) × 频率，先换算位→字节。
6. 复用需锁存器。
7. 总线分时共享 → 同一时刻一对通信 → 瓶颈。

## 真题考法（上午单选）
- 地址总线 N 位 → 寻址空间（2ⁿ）。
- 数据总线 N 位 → 一次传多少字节。
- 复用 + 锁存。
- 带宽计算（位↔字节换算）。

## 我的笔记
- [#N43] 判据 ｜ 数据总线定"宽"（一次多少位），地址总线定"空间"（2ⁿ）
  理: 数据总线像车道宽度，地址总线像门牌号位数
- [#N44] 判据 ｜ 地址单向、数据双向
  理: 地址由 CPU 发出（单向），数据双向传输
- [#N45] 判据 ｜ 位 ÷ 8 = 字节（带宽计算先换算，别把 64 位当 4 字节）
  例: 64 位 = 8 字节；32 位 = 4 字节
- [#N46] 口诀 ｜ 带宽 = 宽度(字节) × 频率 × 每周期次数
  例: 64 位(8B)、50MHz、1 次 → 400 MB/s
- [#N47] 判据 ｜ 复用省引脚、需锁存器（分时复用，地址要锁存给内存）
  理: 地址只在第一阶段出现，后面线变数据，内存需地址保持→锁存
- [#N48] 判据 ｜ 总线分时共享 → 同一时刻一对通信 → 总线瓶颈
  理: 共享资源，分时复用→争用→限制带宽
