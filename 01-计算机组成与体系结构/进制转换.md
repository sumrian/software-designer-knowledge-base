# 进制转换

> 模块：01 计算机组成与体系结构 ｜ 状态：✅ ｜ 2026-07-02 完成

## 定义
进制 = 位置记数法：数值 = 每位数字 × 基^位置。小数点左 0,1,2…次幂（越左越大），右 −1,−2…次幂（越右越小）。转换本质 = 同一个数换个基重新表达，围绕「按权展开」与「凑权」两种思路。

## 要点（含案例）
1. **任意→十：按权展开求和**
   - `1101.101` = 8+4+0+1 + 0.5+0+0.125 = **13.625**
   - `3C` = 3×16+12 = **60**
2. **十→二 整数：除2取余，逆序读**（先得的是最低位）
   - 77 → `1001101`（77÷2…1, 38÷2…0, 19÷2…1, 9÷2…1, 4÷2…0, 2÷2…0, 1÷2…1，从下往上）
3. **十→二 小数：乘2取整，顺序读**（先得的是最高位 2⁻¹）
   - 0.375 → `0.011`（0.375×2→0, 0.75×2→1, 0.5×2→1，从上往下）
   - 合体：77.375 → `1001101.011`
4. **二↔八（3位一组）/二↔十六（4位一组）：直接分组，不绕十进制**
   - 从小数点向两侧展开；整数高位补 0、小数低位补 0
   - `1111010101` → `0011 1101 0101` → `3D5`（=981）
   - `1011.1110` → `B.E`（=11.875）

## 方向为什么相反（别死记）
- 整数最低位 2⁰ 先算出 → 放最右；越后越是高位 → 最后余数是最高位 → **逆序读**。
- 小数最高位 2⁻¹ 先算出 → 放最左；越后越是低位 → **顺序读**。
方向由位权大小决定，理解了不用背。

## 易错点
1. **方向写反**：0.625 正解 `0.101`；若顺序写反成 `0.001`（=0.125）就错。真题常把逆序结果作干扰项（如 0.6875 的 `0.1011` vs 干扰项 `0.1101`）。
2. **补 0 补错位**：整数高位补、小数低位补。`101.1`→八进制：整数 101=5，小数 .1→100(低位补)=4 → `5.4`；若小数高位补成 .001=1 → `5.1` 错。
3. **十进制小数可能无限循环**：0.1 = `0.000110011001…`（"0011"循环）。判断法：化简后分母是 2 的幂才能精确。0.5/0.25/0.125/0.625(=5/8) 能；0.1/0.2/0.3 不能。是浮点数精度的伏笔。
4. **操作判据**：乘 2 取整过程中，小数部分能到 0 → 有限可表示；否则无限循环。
