# PV 经典问题：哲学家进餐

> 模块：02 操作系统 ｜ 状态：🟦
>
> 三种死锁预防方案已完成逐项讲解、自适应训练和针对性补强；尚缺至少 2 道题源明确的软件设计师考生回忆版真题校准。

## 问题模型

N 位哲学家围坐在圆桌旁，每两人之间有一根筷子。哲学家 Pi 需要左筷子 i 和右筷子 `(i+1)%N`，只有取得两根筷子才能进餐。

```text
semaphore chopstick[N] = {1, ..., 1}
```

所有哲学家都先拿左筷子、再拿右筷子时，可能各持有一根并等待下一根，形成完整循环等待。

## 死锁的四个必要条件

1. 互斥：一根筷子同时只能由一人使用。
2. 请求并保持：持有一根筷子继续等待另一根。
3. 不可剥夺：不能强制夺走已分配的筷子。
4. 循环等待：每位哲学家都等待下一位持有的筷子。

## 方案一：限制竞争人数

```text
semaphore room = N - 1;

P(room)
P(left)
P(right)

进餐

V(right)
V(left)
V(room)
```

最多允许 N−1 位哲学家进入“拿筷子—进餐—归还”过程，使圆形等待链留下缺口。缺口旁至少有一位哲学家能够取得第二根筷子并推进系统。

`room` 必须在拿筷子前 P，并在归还两根筷子后 V。提前 `V(room)` 只归还竞争资格，不会归还已持有的筷子，可能让第 N 人进入并重新形成完整等待环。

该方案避免死锁，但若 `room` 的等待队列不公平，个别哲学家仍可能饥饿。

## 方案二：改变资源申请顺序

可以让至少一位哲学家反向申请：

```text
P0～P(N-2)：先左后右
P(N-1)：先右后左
```

也可以按奇偶采用不同顺序，或使用更一般的资源有序分配：

> 每位哲学家都先申请编号较小的筷子，再申请编号较大的筷子。

资源申请不再形成一致方向的闭环，主要破坏循环等待条件。只改变归还顺序无效，因为死锁发生在取得第二根筷子之前。

## 方案三：一次性分配两根筷子

核心规则：

> 两根都能取得才一起分配；只要少一根，就一根也不占用。

服务员或总互斥锁保护下面的复合操作：

```text
检查左右两根筷子是否同时可用
→ 若都可用，同时标记两根为已占用
```

概念性程序：

```text
P(waiter)

if left 和 right 都可用:
    同时标记 left、right 为占用
    V(waiter)
    进餐
    P(waiter)
    同时归还 left、right
    V(waiter)
else:
    不占用任何筷子
    V(waiter)
    等待条件变化后重试
```

`waiter` 只保护资源状态的检查和修改，不应在整个进餐期间持有，否则会不必要地把可并发的进餐串行化。

该方案主要破坏请求并保持条件。N 根筷子时，理论上最多同时有 `floor(N/2)` 位哲学家进餐。

## 关于错误写法的修正

```text
P(waiter)
P(left)
P(right)
V(waiter)
```

这不是一次性分配。若 `left` 可用、`right` 不可用，哲学家会持有 `left` 和 `waiter`，并阻塞在 `P(right)`。

若归还筷子不需要取得 `waiter`，上述具体程序会造成持锁阻塞和并发度下降，但不能仅据此断言必然出现新死锁；如果归还也需要先取得 `waiter`，则可能形成“申请者持有 waiter 等筷子、持筷者等待 waiter 才能归还”的明确死锁闭环。

## 三种方案对比

| 方案 | 核心做法 | 主要破坏或避免 |
| --- | --- | --- |
| 限制人数 | `room=N-1` | 避免形成完整循环等待环 |
| 改变顺序 | 反向、奇偶或资源编号递增 | 破坏循环等待 |
| 一次性分配 | 两根同时取得，否则一根不拿 | 破坏请求并保持 |

三个方案都用于避免死锁，但都不自动保证绝对公平；调度或等待队列不公平时，仍可能发生饥饿。

## 易错点

- `room` 限制的是进入完整竞争过程的人数，不只是正在进餐的人数。
- 第 N 位哲学家在 `room=N-1` 已被占满时阻塞在 `P(room)`，尚未执行任何筷子 P。
- `V(room)` 不会归还筷子；必须归还两根筷子后再释放 room。
- 改变申请顺序能破坏循环等待，只改变归还顺序不能预防死锁。
- 资源有序分配必须先申请较小编号，再申请较大编号。
- 连续执行 `P(left)→P(right)` 不是原子分配，两个 P 之间仍可发生阻塞或进程切换。
- 一次性分配要求“检查两根都可用＋同时标记占用”组成原子操作。
- 等待两根筷子期间不能持有一根筷子，也不能持有 `waiter`。
- 避免死锁只保证系统能推进，不等于每位哲学家都不会饥饿。
