# 前趋图

> 模块：02 操作系统 ｜ 状态：🟦 待与 PV 组合真题校准

## 定义

前趋图是描述任务之间先后依赖关系的有向无环图。若 `A→B`，表示 A 必须完成后 B 才能开始；A 是 B 的前趋任务，B 是 A 的后继任务。

## 要点

- 箭头方向表示“前者完成，后者才具备开始条件”。
- 一个任务有多个直接前驱时，必须等待所有前驱全部完成，默认是 AND 关系。
- 一个任务分出多个后继时，这些后继若彼此没有依赖路径，就允许并发。
- 判断两个任务能否并发，必须检查两个方向是否存在直接或间接路径。
- `A→B→C` 中，A 虽不是 C 的直接前驱，但仍是 C 的间接前驱。
- 前趋图不能有环，否则会形成相互等待，无法得到合法起点。
- 合法执行序列必须满足每条边 `X→Y` 中 X 都出现在 Y 之前，但不要求二者紧邻。

### 例子

已知：

```text
A → B
A → C
B → D
C → D
D → E
```

则：

- A 最先执行。
- A 完成后，B、C 可以并发。
- D 必须等 B、C 全部完成。
- E 必须等 D 完成。
- `A,B,C,D,E` 和 `A,C,B,D,E` 都是合法序列。
- `A,B,D,C,E` 不合法，因为 D 早于其前驱 C。

## 易错点

- 多个前驱不是任选其一，而是全部完成。
- 没有直接箭头不等于可以并发，还要排除间接路径。
- “允许并发”不表示任务一定同时占用 CPU。
- `A→B` 不表示 B 在 A 后必须立刻执行，中间可以穿插其他不冲突任务。
- 不能为了凑真题而提前展开 PV；历年前趋图真题通常与 PV 操作组合命题，应留到相应考点统一校准。

## 真题考法

- 根据图判断可以并发的任务。
- 判断某任务开始前必须完成哪些直接和间接前驱。
- 根据文字描述补全前趋边。
- 判断合法或不合法的执行序列。
- 高频组合题：将前趋图的每条依赖边映射到同步信号量与 P/V 操作；本部分留到后续“信号量与 PV”考点。
