# 存储管理：分段基础与地址转换

> 状态：🟨 初步掌握，待 A/B 级外部校准与延迟复测  
> 学习日期：2026-08-10

## 基本概念

分段按程序逻辑结构划分，如代码段、数据段和栈段。各段具有独立逻辑含义，长度可以不同，便于共享、保护和动态增长。

逻辑地址：

```text
(段号 S，段内偏移 W)
```

段表项至少包含：

- `Base[S]`：该段的物理起始地址；
- `Limit[S]`：该段长度。

## 地址转换

必须按顺序执行：

```text
段号 S
→ 查询第 S 个段表项
→ 取得 Base[S] 和 Limit[S]
→ 检查 0 <= W < Limit[S]
→ 物理地址 = Base[S] + W
```

若 `W>=Limit[S]`，直接判定越界，不能因为能算出一个地址数字就认为访问合法。

> 分段先查长，不过界再加基址。

最大合法偏移是 `Limit-1`。段号不存在时属于段号越界；段号存在但偏移过大时属于段内越界。

## 分页与分段

| 项目 | 分页 | 分段 |
| --- | --- | --- |
| 划分 | 固定大小 | 逻辑模块 |
| 大小 | 页大小相同 | 段长可不同 |
| 表项 | 物理块号 | 基址+段长 |
| 计算 | 块号×页长+偏移 | 基址+偏移 |
| 碎片 | 内部碎片 | 外部碎片 |
| 共享保护 | 逻辑含义较弱 | 以逻辑段为单位更自然 |

基本分段中，一个段内部通常占用连续物理空间；不同段之间可以分散、乱序存放，不必相邻或按段号排列。

## 个人易错点

1. 逻辑地址 `(S,W)` 必须查询第 S 个段表项，不能按物理基址大小或表中顺序选择其他段。
2. 地址转换必须先检查段长，再加基址。
3. 偏移等于段长已经越界，合法范围是 `0～Limit-1`。
4. 段长不是物理结束地址，物理范围是 `Base～Base+Limit-1`。
5. 能算出物理地址数字不代表合法，越界地址可能落入其他段或未授权区域。
6. 分段不能套用分页的除法取商余规则。
7. 一个段内部连续，不同段之间不要求连续。
