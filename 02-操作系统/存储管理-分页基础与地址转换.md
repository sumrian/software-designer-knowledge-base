# 存储管理：分页基础与地址转换

> 状态：🟨 初步掌握，待延迟复测  
> 学习日期：2026-08-10

## 基本概念

- 逻辑地址空间按固定大小划分为页（Page）。
- 物理内存按同样大小划分为页框或物理块（Frame）。
- 页表记录“逻辑页号 → 物理块号”。
- 页与页框大小相同，因此地址转换后页内偏移保持不变。

分页不产生外部碎片，但程序最后一页可能产生内部碎片。

## 地址拆分

设逻辑地址为 `A`，页大小为 `L`：

```text
页号 P = A // L
页内偏移 W = A % L
```

验证：

```text
A = P × L + W
```

页号从 0 开始已经体现在整数除法中，不能再减 1。

页号为 `k` 的逻辑地址范围：

```text
kL ～ (k+1)L-1
```

## 物理地址转换

页表查得物理块号 `F` 后：

```text
物理地址 = F × L + W
```

页表只替换逻辑页号，偏移原样带入。

由 `A=P×L+W` 可推出个人使用的快捷验算式：

```text
物理地址 = A + (F-P) × L
```

该公式是正确的，但标准公式更直接。2007 年真题中使用快捷公式的思路正确，错误仅是把 25996 加成 26996，属于算术失误，不能误记为未查页表。

## 地址位划分

若页大小为 `2ⁿ B`：

- 低 `n` 位是偏移；
- 剩余高位是页号；
- `总地址位数 = 页号位数 + 偏移位数`。

例如 20 位地址、4 KB 页：

```text
4 KB = 2¹² B
偏移 = 12 位
页号 = 20-12 = 8 位
```

十六进制下，4 KB=`0x1000`，低 3 个十六进制位就是 12 位偏移。逻辑地址 `0x2C25` 的页号为 2、偏移为 `0xC25`；若页 2 映射到块 5，物理地址为 `0x5C25`。

## 页数与内部碎片

程序所需页数必须向上取整：

```text
页数 = ceil(程序大小 / 页大小)
内部碎片 = 页数×页大小 - 程序大小
```

内部碎片只可能出现在最后一页。

## 个人易错点

1. 页号是整数商，不额外减 1。
2. `//` 取商得到页号，`%` 取余得到偏移。
3. 总地址位数中已经包含偏移位，页号位数必须用减法求。
4. 判断逻辑页范围要使用逻辑地址，不能拿转换后的物理地址验证。
5. 页号 `k` 的范围是 `kL～(k+1)L-1`，页号 3 是第 4 个页。
6. 标准物理地址公式用块号和偏移；差值快捷公式也可用于验算。
7. 页数向上取整，不能把普通除法直接写成页数等式。
