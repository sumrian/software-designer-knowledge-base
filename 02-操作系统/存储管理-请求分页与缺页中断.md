# 请求分页与缺页中断

## 核心概念

请求分页只在页面被实际访问时调入内存，依赖程序局部性减少内存占用和不必要的磁盘读入。

| 字段 | 含义 |
| --- | --- |
| V（有效/驻留位） | 1 表示页面在内存；0 可能是合法但尚未调入，也可能是非法页面，必须结合地址合法性判断 |
| 物理块号 | 页面驻留时所在页框 |
| R（访问位） | 页面被读或写后置 1，供置换算法判断近期使用情况 |
| M（修改/脏位） | 页面被写后置 1；脏页淘汰前必须写回 |
| 保护位 | 控制可读、可写、可执行等权限 |
| 外存位置 | 页面不在内存时用于定位后备存储 |

读访问使 R=1、M 保持原值；写访问使 R=1、M=1。记忆：**读过就置 R，写过还要置 M。**

## 缺页处理流程

1. 访问页面发现 V=0，触发缺页异常。
2. 先检查地址和权限是否合法；非法访问直接报错。
3. 有空闲页框就直接使用；没有才选择淘汰页。
4. 淘汰页若 M=1，先写回外存；M=0 可直接覆盖。
5. 从外存调入目标页，进程在磁盘 I/O 期间阻塞。
6. 更新旧页、新页的页表项及相关 TLB 项。
7. 恢复后重新执行引发缺页的原指令。

> **无效先判合法，有空框直接装；无空框才置换，脏页先写回；映射更新后，原指令重来。**

缺页由当前指令同步触发，属于内部异常；缺页处理中磁盘 I/O 完成中断来自外部设备。

## 换页时的映射一致性

假设淘汰页 1 所在块 7，并把页 2 装入块 7：

| 对象 | 更新 |
| --- | --- |
| 旧页 1 页表项 | V=0，块号失效 |
| 新页 2 页表项 | V=1，块号 7，按实际访问设置 R/M |
| 页 1 的 TLB 项 | 删除或置失效 |
| 页 2 的 TLB 项 | 可插入或更新为“页2→块7” |

不能让页 1 继续保持 V=1、块号 7，否则页 1 和页 2 会错误地同时指向同一页框。

> **旧页要注销，新页要登记；旧快表也必须作废。**

## 易错边界

- V=0 不等于一定非法，要先检查是否属于合法地址空间。
- 有空闲页框时不淘汰。
- 只有脏页淘汰时必须写回。
- 缺页处理完成后重新执行原指令，不是直接执行下一条。
- 页面淘汰后页表与 TLB 都要保持一致，不能只更新新页。
- R 判断近期访问，M 决定是否写回，职责不同。
