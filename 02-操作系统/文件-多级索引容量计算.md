# 文件：多级索引容量计算

## 定义与模型

多级索引用“索引块指向索引块”的方式扩大单个文件可寻址的数据块数量。

- 直接索引：索引项直接保存数据块号。
- 一级间接：索引项指向 1 个索引块，该索引块再保存数据块号。
- 二级间接：索引项指向一级索引块，一级索引块中的每个地址再指向一个二级索引块，最终定位数据块。
- 三级间接：在二级间接基础上再增加一层地址表。

每多一级间接，就多经过一层地址表。

## 核心公式

设：

- 数据块/索引块大小为 `B` 字节；
- 每个块地址占 `P` 字节；
- 一个索引块能保存的地址数为 `N`。

则：

```text
N = B / P
```

单个索引项最多覆盖的数据块数：

```text
直接索引：1
一级间接：N
二级间接：N²
三级间接：N³
```

若索引节点含 `d` 个直接索引项、`s` 个一级间接索引项、`t` 个二级间接索引项，则最大可定位数据块数：

```text
d + sN + tN²
```

若还有 `u` 个三级间接索引项，则再加 `uN³`。

最大文件数据容量：

```text
可定位的数据块数 × 数据块大小 B
```

注意：这里计算的是**文件数据容量**，间接索引块本身属于管理开销，不计入文件正文长度。

## 逻辑块号边界

软件设计师题目中的逻辑块号通常按 **0 基编号**处理。

若有 `d` 个直接索引项：

```text
直接索引：0 ～ d-1
一级间接总范围：d ～ d+sN-1
二级间接起点：d+sN
```

例如 `d=5, s=2, N=256`：

```text
直接：0～4
第 1 个一级间接：5～260
第 2 个一级间接：261～516
二级间接：从 517 开始
```

因此逻辑块 5 用一级间接；逻辑块 518 用二级间接。

## 易错点

1. **间接级数决定指数**：一级 `N`、二级 `N²`、三级 `N³`；不能把二级写成 `N^N`。
2. 多个一级间接索引项要乘个数，例如 2 个一级间接覆盖 `2N`，不是 `N²`。
3. “第 n 个数据块”通常是 1 基自然语言；“逻辑块号 n”通常是 0 基编号，二者差 1。
4. 区间末端要用 `起点 + 覆盖数量 - 1`，避免整体偏 1。
5. 计算最大文件长度时只统计可寻址的数据块容量；若题目问“实际占用磁盘块数”，才需要额外考虑索引块开销。
