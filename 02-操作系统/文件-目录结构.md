# 文件：目录结构

## 定义

目录结构用于组织文件名，并通过目录项把文件名与对应的文件控制信息或文件位置关联起来。

目录本身可以理解为一种特殊的数据结构。对用户来说，目录提供分层命名空间；对操作系统来说，目录项承担“根据名字找到文件”的入口作用。

## 常见目录结构

### 单级目录

所有文件放在同一个目录中。

- 优点：实现简单。
- 缺点：文件多时管理困难；不同用户或不同用途的文件容易发生重名冲突。

### 二级目录

通常由主目录区分用户，每个用户再拥有自己的用户文件目录。

- 不同用户可以拥有同名文件。
- 目录层次固定，分类能力弱于树形目录。

### 树形目录

目录下还可以继续建立子目录，形成多层树结构。

- 便于分层组织和分类管理。
- 不同目录下可以存在同名文件。
- 文件通常由完整路径唯一定位。

例如：

```text
/
├── userA
│   ├── docs
│   │   └── a.txt
│   └── a.txt
└── userB
    └── a.txt
```

三个 `a.txt` 可以同时存在，因为它们位于不同路径。

## 绝对路径与相对路径

### 绝对路径

从根目录开始定位文件。

例如：

```text
/userA/docs/a.txt
```

### 相对路径

从当前工作目录开始定位文件。

若当前目录为：

```text
/userA
```

则目标 `/userA/docs/a.txt` 的相对路径为：

```text
docs/a.txt
```

若目标不在当前目录的子树中，可以使用父目录符号 `..` 向上返回后再进入目标目录。

例如当前目录：

```text
/home/user/project/src
```

目标：

```text
/home/user/docs/spec.txt
```

相对路径为：

```text
../../docs/spec.txt
```

## 高频判据

- 相对路径的起点：**当前目录**。
- 绝对路径的起点：**根目录**。
- 不同目录下可以存在同名文件。
- 树形目录可以继续多层嵌套，不是固定两层。
- 二级目录通常是“主目录 → 用户文件目录”，不要与可任意嵌套的树形目录混淆。

## 易错点

- 目录保存的是文件管理和定位信息，不等同于文件正文。
- 不要误认为树形目录要求文件名全局唯一；通常只要求同一目录内不能重名。
- 相对路径不要机械地添加根目录分隔符；一旦从根开始表达，就已经是在写绝对路径。
- 看到 `..` 时应逐级退回父目录，再从共同祖先目录进入目标路径。

## 真题考法

常见题型：

1. 判断单级、二级、树形目录的特点。
2. 根据当前工作目录和目标位置判断绝对路径/相对路径。
3. 判断不同目录下同名文件是否合法。
4. 根据 `..` 计算跨父目录的相对路径。
