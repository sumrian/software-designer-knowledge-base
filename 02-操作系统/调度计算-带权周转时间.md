# 调度计算：带权周转时间

> 模块：02 操作系统 ｜ 状态：🟦（待考生回忆版真题校准）

## 定义

带权周转时间（周转系数）用服务时间对周转时间进行归一化，反映进程相对于自身运行需求受到的延迟程度。

## 要点

- `带权周转时间 = 周转时间 / 服务时间`。
- `周转时间 = 完成时刻 - 到达时刻`，因此不能直接用完成时刻作分子。
- 无 I/O 阻塞时，`带权周转 = 1 + 等待时间 / 服务时间`。
- 没有等待时带权周转等于 1；一般 CPU 调度题中结果应不小于 1。
- 平均带权周转必须先计算每个进程的比值，再对这些比值求平均。
- 带权周转没有时间单位，数值越小通常表示相对延迟越低。
- 相同等待时间对短作业的相对影响更大，因此短作业可能拥有更高的带权周转值。

## 易错点

- 分母是该进程自己的服务时间，不能错配其他进程的分母。
- `平均带权周转` 通常不等于 `平均周转 / 平均服务`；分母不同不能合并换算。
- 最终平均值正确不代表逐项过程正确，交换两个单项值可能让总和碰巧不变。
- 普通周转衡量绝对耗时；带权周转衡量相对于自身服务时间的延迟。

## 真题考法

- 根据到达、完成和服务时间计算单个进程的带权周转。
- 从 FCFS、SJF、RR 等执行时间轴计算平均带权周转。
- 判断平均值的正确计算方式以及指标是否有单位。
- 比较不同调度顺序的平均带权周转，识别短作业被长作业护航的影响。
