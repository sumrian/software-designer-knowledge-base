# 调度计算：等待时间与周转时间

> 模块：02 操作系统 ｜ 状态：🟦（待考生回忆版真题校准）

## 定义

- 周转时间：进程从到达系统到最终完成所经历的总时间。
- 等待时间：在仅考虑 CPU 调度且无 I/O 阻塞的题型中，进程处于就绪状态、等待 CPU 的总时间。

## 要点

- `周转时间 = 完成时刻 - 到达时刻`。
- 无 I/O 阻塞时，`等待时间 = 周转时间 - 服务时间`。
- 非抢占且只等待一次时，也可用 `等待时间 = 开始时刻 - 到达时刻`。
- 抢占式调度可能产生多段等待，优先使用通用式：`等待 = 完成 - 到达 - 服务`。
- 平均指标等于各进程对应指标之和除以进程数。
- 固定计算顺序：按算法画时间轴 → 确定完成时刻 → 算周转 → 算等待 → 算平均值。

## 易错点

- 完成时刻不等于周转时间；只有到达时刻为 0 时两者数值才相同。
- 服务时间只是真正占用 CPU 的时间，不包含就绪等待。
- CPU 在进程到达前的空闲时间不属于该进程的等待时间。
- 到达时刻不为 0 时，不能把开始时刻直接当等待时间，必须用 `开始 - 到达`。
- 抢占式调度不能只计算首次运行前的等待；应累计全部等待段或使用通用公式。

## 真题考法

- 给出到达时刻、服务时间和调度算法，计算完成、等待和周转时间。
- 计算平均等待时间、平均周转时间。
- 在 FCFS、SRTF、RR 等时间轴中处理抢占、分段运行和 CPU 空闲。
- 比较不同执行顺序下的调度性能。
