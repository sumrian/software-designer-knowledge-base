# 页面置换：LRU

## 定义

LRU（Least Recently Used，最近最少使用）在发生缺页且页框已满时，淘汰**过去最长时间没有被访问**的页面。

判断方向：

- OPT：看未来，淘汰未来最晚再用/不再使用的页。
- FIFO：看进入内存的先后，淘汰最早进入的页。
- LRU：看过去，淘汰最近一次访问离当前最远的页。

## 核心规则

1. 从左到右处理页面访问序列。
2. 命中：不缺页，但必须刷新该页的“最近使用时间”。
3. 未命中且有空页框：装入，计 1 次缺页，不计置换。
4. 未命中且页框已满：从当前驻留页中找最近一次访问最早的页淘汰，计 1 次缺页和 1 次置换。

手算时可维护“最新 → 最旧”的顺序：

- 命中某页：把它移到最前。
- 装入新页：把新页放到最前。
- 需要淘汰：删除最末尾的页。

## 与 FIFO 的高频区别

命中是两者最容易混淆的地方：

- FIFO 命中后，进入顺序不变。
- LRU 命中后，最近使用顺序必须刷新。

例如 3 个页框访问 `1 → 2 → 3 → 1 → 4`：

- FIFO 仍认为 1 最早进入，因此淘汰 1。
- LRU 因为第 4 步刚访问过 1，因此淘汰 2。

## Belady 异常

LRU 属于栈算法，增加页框时较小页框中的驻留集合可包含在较大页框的驻留集合中，因此不会出现 FIFO 那种 Belady 异常。

## 缺页与置换次数

缺页不等于置换。

- 初始空页框装入：缺页，但不淘汰旧页。
- 页框满后缺页：同时发生页面置换。

若初始为空、最终确实装满 F 个页框，则常见场景下：

`置换次数 = 缺页次数 - F`

更通用的说法是：

`置换次数 = 缺页次数 - 利用空页框装入的次数`

## 矩阵/数组访问题

这类题不要默认“一行 = 一页”。先统一换算成元素数量：

1. 每行元素数 = 列数。
2. 矩阵总元素数 ÷ 每页元素数 = 实际页面数（最后一页可能未装满）。
3. 连续按行访问时，每进入一个新的页面才会产生该页的首次缺页。
4. 结束时最后若干页框覆盖多少行，要按这些页面中的**有效矩阵元素区间**计算。

只有当“每页元素数”能和“每行元素数”恰好对齐时，才能直接说每页对应整数行数。

## 易错点

- 把“最近一次访问时刻最早”说成“访问时间最长”，方向容易混乱；更稳妥的说法是“离当前最久未访问”。
- 命中后忘记刷新最近使用时间。
- 把 FIFO 的“最早进入”当成 LRU 的“最久未访问”。
- 把缺页次数直接当置换次数。
- 矩阵题中未经换算就假设一行等于一页。
