# IP 编址：前缀/掩码与网络号主机号

## 定义

IPv4 地址长度为 32 位。CIDR 前缀 `/n` 表示前 `n` 位是网络位，剩余 `32-n` 位是主机位。

例如：

`192.168.10.35/24`

表示前 24 位是网络位，后 8 位是主机位。

## 前缀长度与子网掩码

子网掩码中连续的 `1` 对应网络位，连续的 `0` 对应主机位。

常见映射：

- `/8 = 255.0.0.0`
- `/16 = 255.255.0.0`
- `/24 = 255.255.255.0`
- `/25 = 255.255.255.128`
- `/26 = 255.255.255.192`
- `/27 = 255.255.255.224`
- `/28 = 255.255.255.240`
- `/29 = 255.255.255.248`
- `/30 = 255.255.255.252`

例如：

`192 = 11000000`，因此 `255.255.255.192` 一共有 `24+2=26` 个连续的 `1`，即 `/26`。

## 网络位与主机位

IPv4 总位数固定为 32：

`主机位数 = 32 - 前缀长度`

例如：

- `/24 → 8` 位主机位
- `/26 → 6` 位主机位
- `/28 → 4` 位主机位
- `/20 → 12` 位主机位

口诀：**斜杠数网络位，32 减它主机位；掩码 1 是网络，0 是主机。**

## 前缀长短与网络范围

前缀越长：

- 网络位越多
- 主机位越少
- 单个网络覆盖的地址范围越小
- 网络越具体

因此 `/28` 比 `/24` 更具体，但可容纳的地址更少。

## 地址数量

若主机位为 `h`，一个子网包含的地址总数为：

`2^h`

传统 IPv4 子网中，可用主机数通常为：

`2^h - 2`

其中减去网络地址和广播地址。该部分会在下一最小子点继续展开。

## 易错点

- `/26` 表示 26 位网络位，不是 26 位主机位。
- 主机位不能默认按最后一个字节的 8 位来算，必须用 `32 - 前缀长度`。
- 子网掩码中的非 255 字节应先转二进制数连续的 `1`。
- 前缀越长，网络范围越小，不是越大。
- “地址总数”和“可用主机数”不是同一个概念。
