## 定义

DHCP（Dynamic Host Configuration Protocol）是应用层协议，用于为主机自动分配和下发网络配置参数，包括 IP 地址、子网掩码、默认网关、DNS 服务器地址等。

## 要点

- DHCP 使用 UDP。
- DHCP 服务器常用端口 67，客户端常用端口 68。
- 初始客户端通常还没有可用 IP 地址，但已有网卡 MAC 地址，可以在局域网中广播寻找 DHCP 服务器。
- 典型初始 Discover 可表现为源 IP `0.0.0.0`、目的 IP `255.255.255.255`。
- DORA 四步：`Discover → Offer → Request → ACK`。
- 记忆：发现 → 提供 → 请求 → 确认。

## 易错点

1. DHCP ≠ DNS：DHCP 分配网络参数；DNS 做域名解析。
2. DHCP 不只分配 IP，还可下发掩码、网关、DNS 等参数。
3. 端口不要写反：服务器 67，客户端 68。
4. DORA 顺序固定：收到 Offer 后由客户端发送 Request，最后服务器 ACK。
5. DHCP 客户端开始时不需要先拥有一个私有 IP 地址；若后续 DHCP 失败，部分系统可能使用 IPv4 链路本地地址 `169.254.0.0/16`，这不是 DHCP 正常流程的前置条件。
