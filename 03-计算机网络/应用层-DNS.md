# 应用层：DNS

- 状态：🟦 学习中（合格软件设计师回忆版真题 1/2）
- 学习日期：2026-08-18

## 定义

DNS（Domain Name System，域名系统）属于应用层协议，核心作用是把域名解析为 IP 地址，并通过分布式、层次化的命名体系组织解析信息。

## 要点

- 默认端口：53。
- 常规查询通常使用 UDP；部分场景会使用 TCP。
- 常见资源记录：
  - `A`：域名 → IPv4 地址。
  - `AAAA`：域名 → IPv6 地址。
  - `CNAME`：别名 → 规范域名。
  - `MX`：邮件交换服务器。
  - `NS`：权威 DNS 服务器。
- DNS 与 DHCP 不同：DNS 负责名称解析；DHCP 负责动态分配 IP 等网络参数。

## 易错点

1. DNS 不是“只能 UDP”；常规查询多用 UDP 53，某些场景会用 TCP 53。
2. `A` 只对应 IPv4，IPv6 使用 `AAAA`。
3. `MX` 指向邮件交换服务器，不是 Web 服务器。
4. `CNAME` 表示别名关系，不是直接写 IP 地址。
5. DNS 自身是应用层协议，即使底层使用 UDP/TCP，也不会变成传输层协议。

## 真题考法

- 判断 DNS 所属层次。
- 判断默认端口 53。
- 判断 UDP/TCP 的使用场景。
- 识别 `A/AAAA/CNAME/MX/NS` 记录类型。
- 区分 DNS 与 DHCP。
