## 定义

FTP（File Transfer Protocol，文件传输协议）用于客户端与服务器之间传输文件，属于应用层协议。

## 核心要点

- FTP 使用 TCP。
- 控制连接与数据连接分离。
- 控制连接通常连接服务器 TCP 21 端口，用于命令与响应。
- 文件内容、目录列表等通过单独的数据连接传输。
- 主动模式（PORT）：服务器主动连接客户端的数据端口。
- 被动模式（PASV）：客户端主动连接服务器提供的数据端口。
- FTP 默认不提供加密保护，用户名、密码及数据可能明文传输。
- SFTP 基于 SSH；FTPS 是 FTP + TLS。
- TFTP 与 FTP 不同：TFTP 使用 UDP，协议更简单。

## 易错点

1. 不要把 FTP 误认为 UDP；FTP 使用 TCP。
2. TCP 21 主要是控制连接，不代表文件数据一定也走同一条 21 端口连接。
3. FTP 默认不是安全加密协议。
4. SFTP 不是 FTP + TLS；FTP + TLS 是 FTPS。
5. 主动/被动模式的“主动方”指数据连接由谁发起：主动模式服务器发起，被动模式客户端发起。
