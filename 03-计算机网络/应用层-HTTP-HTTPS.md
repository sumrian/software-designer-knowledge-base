# 应用层：HTTP/HTTPS

- 状态：🟦 学习中（基础掌握；合格软件设计师回忆版真题校准 1/2）
- 学习日期：2026-08-18

## 定义

HTTP 是应用层的 Web 通信协议，采用请求/响应模型，协议本身无状态。HTTPS 可理解为 HTTP 在 TLS 保护下进行通信，使传输具备机密性、完整性保护和身份认证能力。

## 要点

- HTTP 默认端口：80。
- HTTPS 默认端口：443。
- HTTP 常见方法：GET 获取资源，POST 提交数据。
- 常见状态码类别：2xx 成功，3xx 重定向，4xx 客户端请求类问题，5xx 服务器端错误。
- `404 Not Found`：请求资源未找到。
- `500 Internal Server Error`：典型服务器内部错误。
- HTTP 无状态：协议默认不自动保存前后请求之间的会话状态；Cookie/Session 可由应用层机制维持会话，但不改变 HTTP 本身无状态的基本属性。
- HTTPS/TLS 主要提供：加密、完整性保护、身份认证。

## 易错点

1. HTTPS 保护的是通信过程，不代表网站内容一定真实，也不代表网站绝不会被攻击。
2. HTTP 无状态不等于每次都必须重新建立 TCP 连接；可使用持久连接。
3. 404 与 500 不要混淆：404 是资源未找到，500 才是典型服务器内部错误。
4. HTTPS 不是自动保存登录状态的机制；会话状态通常由 Cookie/Session 等机制实现。
5. 安全协议分类题要按“主要用途”判断：IPsec 用于保护 IP 通信，SFTP 用于安全文件传输，HTTPS 用于安全 Web 通信，SNMP 的主要用途是网络管理。

## 真题考法

- HTTP/HTTPS 默认端口。
- 状态码类别及 404/500 的含义。
- HTTP 无状态与 Cookie/Session 的关系。
- HTTPS/TLS 的安全能力。
- 数字证书用于服务器身份认证。
- 协议主要用途分类：HTTPS、IPsec、SFTP、SNMP。
