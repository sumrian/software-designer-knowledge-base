# 数据链路：MAC 地址与帧转发基础

- 状态：🟦 待第二道回忆版真题校准
- 日期：2026-08-14

## 定义
MAC 地址用于数据链路层的本地链路交付；以太网 MAC 地址通常为 48 位（6 字节）。以太网帧头包含源 MAC 与目的 MAC。

## 要点
- MAC → 数据链路层；IP → 网络层。
- IP 关注端到端最终目的地，MAC 关注当前这一跳的交付对象。
- 同网段通信：目的 MAC 通常是目标主机 MAC。
- 跨网段通信：目的 IP 仍是最终服务器 IP，但第一跳目的 MAC 是默认网关/下一跳路由器接口的 MAC。
- 经过路由器后，链路层帧会重新封装，因此源/目的 MAC 可变化，而最终目的 IP 通常保持不变。
- 以太网广播 MAC：`FF:FF:FF:FF:FF:FF`，仅表示当前广播域内广播。

## 易错点
- 不要把 MAC 与 IP 都当成同一层地址。
- 跨网段时不要把远端服务器 MAC 写进第一跳帧；第一跳先交给默认网关。
- 广播 MAC 不是“互联网全网广播”。
