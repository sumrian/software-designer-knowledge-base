# 网络分层：OSI 七层层次与核心职责

- 状态：🟦 待真题校准
- 日期：2026-08-14

## 七层顺序

`物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层`

## 核心职责

- 物理层：传比特，关注信号、接口、电气特性。
- 数据链路层：传帧，处理相邻节点之间的数据传输与 MAC 寻址。
- 网络层：逻辑寻址、跨网络转发、路由选择，解决“到哪台主机”。
- 传输层：端到端、进程到进程传输，结合端口区分目标进程，解决“到主机里的哪个程序”。
- 会话层：建立、管理、终止会话。
- 表示层：数据格式转换、编码、压缩、加密/解密。
- 应用层：直接向用户应用提供网络服务。

## 易错点

- “经过多个路由器、选择下一跳/路径”属于网络层，不属于传输层。
- “数据已到目标主机，根据端口交给正确应用进程”属于传输层。
- 记忆模型：网络层管“快递到哪栋楼”，传输层管“到了楼里交给哪一户”。
- 表示层常见关键词：格式转换、编码、压缩、加密/解密。
- 设备归层需单独记忆：Hub 常见归物理层，以太网交换机常见归数据链路层，路由器归网络层；该内容属于后续“典型协议/设备归层”子点重点。
