# 网络分层：TCP/IP 四层及与 OSI 映射

- 状态：🟦 待真题校准
- 日期：2026-08-14

## 核心映射
- TCP/IP 网络接口层 ≈ OSI 物理层 + 数据链路层
- TCP/IP 网际层 ≈ OSI 网络层
- TCP/IP 传输层 ≈ OSI 传输层
- TCP/IP 应用层 ≈ OSI 会话层 + 表示层 + 应用层

## 记忆模型
- 下二合一：物理层 + 数据链路层 → 网络接口层
- 中间两层基本一一对应：网络层 → 网际层；传输层 → 传输层
- 上三合一：会话层 + 表示层 + 应用层 → TCP/IP 应用层
- 可记为 OSI 对 TCP/IP 的层数分组：`2 - 1 - 1 - 3`

## 易错点
- TCP/IP 的“网际层”对应 OSI 网络层，不是应用层。
- TCP/IP 应用层的范围比 OSI 应用层更大，连同会话层、表示层职责一起纳入。
- TCP/IP 网络接口层通常同时覆盖 OSI 物理层和数据链路层，而不只对应数据链路层。
