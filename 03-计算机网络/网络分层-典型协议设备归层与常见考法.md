## 定义

本子点要求看到典型网络协议、地址或设备时，能判断其主要工作在 OSI 的哪一层。重点是建立“设备/协议—所处理的信息—层次”的稳定映射，不展开各协议内部机制。

## 要点

- 物理层：Hub（集线器）、中继器；处理比特/信号。
- 数据链路层：二层以太网交换机、网桥、MAC；交换机根据目的 MAC 转发帧。
- 网络层：路由器、IP、ICMP；路由器根据 IP 与路由表选择下一跳。
- 传输层：TCP、UDP、端口号；负责进程到进程的传输。
- 应用层：HTTP、FTP、SMTP、DNS、DHCP 等，为具体应用提供服务。

记忆主线：`信号看物理，MAC 看链路，IP 看网络，端口看传输，具体服务看应用。`

## 易错点

1. Hub ≠ 交换机：Hub 只做比特级转发，归物理层；二层交换机识别 MAC 并转发帧，归数据链路层。
2. 交换机 ≠ 路由器：交换机典型看 MAC，路由器典型看 IP。
3. TCP 与 IP 虽常连写为 TCP/IP，但 TCP 属传输层，IP 属网络层。
4. DNS、DHCP 即使使用 UDP/TCP 作为下层传输，自身仍是应用层协议。
5. VLAN 基于二层交换/MAC 的逻辑分组，典型归数据链路层。

## 真题考法

- 给设备判断所属层次：Hub、交换机、路由器。
- 给地址或关键字判断层次：MAC、IP、端口。
- 给协议组合判断层次：TCP/UDP、IP/ICMP、HTTP/DNS 等。
- 给封装链判断由高到低层次，例如 `HTTP → TCP → IP → 以太网帧`。
