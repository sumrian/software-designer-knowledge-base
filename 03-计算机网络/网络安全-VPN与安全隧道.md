# 网络安全：VPN 与安全隧道

## 1. 核心定义

VPN（Virtual Private Network，虚拟专用网）是在公共网络之上，通过隧道封装，并结合加密、认证、完整性保护等机制建立逻辑上的安全专用通道。

核心理解：**公网承载 + 逻辑隧道 + 安全机制**，并不等于物理专线。

## 2. 常见场景

- **远程访问 VPN**：单个用户从外部网络安全接入企业内网，例如员工居家办公。
- **站点到站点 VPN**：两个网络/局域网之间建立长期安全互联，例如总部与分公司。

## 3. 隧道技术

隧道的本质是把原始报文再次封装后通过中间网络传输，到达隧道端点后解封装并恢复原始报文。

易错点：**隧道封装本身不等于加密**。如果要求机密性，还必须使用相应加密机制。

## 4. IPsec 高频考点

IPsec 是常见的网络层安全协议族，常用于 VPN。

- **AH（Authentication Header）**：重点提供数据源认证、完整性等保护，不提供载荷加密保密。
- **ESP（Encapsulating Security Payload）**：可提供加密保密，并可结合认证/完整性保护。

考试判断口诀：

> **保密找 ESP；AH 不负责加密。**

## 5. 易错点

1. VPN 通常借助公网建立逻辑专用网络，不是必须铺设物理专线。
2. 隧道解决封装和跨网络承载问题，不代表天然具备保密性。
3. 单个用户接入公司内网属于远程访问 VPN；两个局域网互联属于站点到站点 VPN。
4. IPsec VPN 的核心安全机制可涉及隧道、加密、身份认证和完整性保护；入侵检测属于 IDS/IPS 范畴，不是 IPsec VPN 本身的基本组成技术。
