# 网络安全：对称加密与非对称加密

## 定义

- 对称加密：加密和解密使用同一个共享密钥。
- 非对称加密：使用一对不同但相关的密钥，即公钥和私钥。

## 核心要点

- 对称加密速度快、计算开销较小，适合大量数据加密，但存在共享密钥安全分发问题。
- 典型对称算法：DES、3DES、AES。
- 非对称加密速度相对较慢，常用于密钥交换、身份认证、数字签名等场景。
- 典型公开密钥/非对称体系：RSA、ECC；DSA 是数字签名算法，也属于公开密钥密码体系。
- 机密通信典型方向：发送方使用接收方公钥加密，接收方使用自己的私钥解密。
- 实际安全通信常采用混合方式：先借助非对称机制建立/交换会话密钥，再用对称算法高效加密大量数据。

## 易错点

1. 不要把 DES/AES 与 RSA/ECC 分类混淆：`DES / 3DES / AES → 对称`，`RSA / ECC → 非对称`。
2. DSA 主要用于数字签名，不是对称算法；考试分类题通常归入公开密钥密码体系。
3. “接收方公钥加密、接收方私钥解密”解决的是保密；“私钥签名、公钥验证”属于数字签名，后续单独学习。
