# SQL：子查询

> 模块：04 数据库系统 ｜ 状态：🟦

## 定义
子查询是嵌套在外层 SQL 中的 `SELECT`，内层结果供外层使用。

## 要点
- 聚合子查询（如 `AVG`、`MAX`、`COUNT`）通常返回一个值，可用于比较。
- `IN` 接收一列多行结果，判断外层值是否属于集合。
- `EXISTS` 只判断子查询是否至少返回一行，常写 `SELECT 1`。
- 子查询引用外层列时是相关子查询，会随外层当前行变化。
- `NOT IN` 的子查询结果含 `NULL` 时可能产生 `UNKNOWN`，结果不完整；可考虑 `NOT EXISTS`。

## 易错点
- 区分标量子查询、多行 `IN` 子查询和 `EXISTS`；不要把聚合子查询误判为多行。
- 外层别名不能直接作为内层 `FROM` 的表名；内层需重新扫描基本表并使用新别名。

## 真题考法
- 判断子查询返回基数，补写 `IN`/`EXISTS`，分析相关引用及 `NOT IN` 与 `NULL`。
