# 关系代数：选择与投影

> 模块：04 数据库系统 ｜ 状态：🟦 待真题校准

## 定义

选择和投影都是一元关系运算：

- 选择 `σ`：根据条件筛选元组，即筛行。
- 投影 `π`：保留指定属性，即挑列。

运算结果仍然是关系，可以继续参与其他关系运算。

## 要点

### 1. 选择筛行

```text
σ_{条件}(关系)
```

例如：

[
sigma_{专业='计算机' land 年龄>20}(学生)
]

结果保留学生关系的全部属性，只留下同时满足两个条件的元组。

常见条件符号包括：

[
=,
e,>,<,ge,le,land,lor,
eg
]

### 2. 投影挑列并消除重复

```text
π_{属性列表}(关系)
```

例如：

[
pi_{姓名,专业}(学生)
]

只保留姓名和专业。在经典关系代数的集合语义下，投影后完全相同的元组只保留一份。

因此：

[
pi_{专业}(学生)
]

更接近 SQL 的：

```sql
SELECT DISTINCT 专业
FROM 学生;
```

### 3. 组合表达式从内向外执行

查询年龄大于 19 岁学生的姓名：

[
pi_{姓名}left(sigma_{年龄>19}(学生)ight)
]

执行过程：

1. 内层 `σ` 按年龄条件筛行。
2. 外层 `π` 只保留姓名列。
3. 投影结果若有重复姓名，按经典集合语义去重。

### 4. 从题干构造表达式

先提取两类信息：

- “满足什么条件”放入 `σ` 的下标。
- “输出哪些字段”放入 `π` 的下标。

例如，查询金额不少于 1000 元且状态为已完成的订单号和客户号：

[
pi_{订单号,客户号}
left(
sigma_{金额ge1000land 状态='已完成'}(订单)
ight)
]

## 易错点

- 受 SQL 的 `SELECT` 关键字干扰，把关系代数的选择与投影混淆。
- 组合条件中漏写“且／或”连接的某个条件；应先圈出全部条件，再用 `∧/∨` 连接。
- 用 `σ` 表示需要输出的列；输出列必须放入 `π`。
- 忘记从内向外执行表达式。
- 先投影掉后续选择条件需要的属性，导致无法继续判断条件。
- 误认为选择阶段会消除投影后的重复；去重发生在投影结果中。

构造口诀：

> 条件放 σ，输出列放 π；先筛行再挑列，从内向外算；投影重复只留一份。

## 真题考法

- 判断 `σ` 和 `π` 分别改变行还是列。
- 根据自然语言需求选择或补写关系代数表达式。
- 给出具体关系表，计算选择、投影及组合运算结果。
- 判断投影后产生的重复元组如何处理。
- 判断某种投影顺序是否提前删除了选择条件所需属性。
- 对照 SQL 的 `WHERE`、字段列表与 `DISTINCT`。
