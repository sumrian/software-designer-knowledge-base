## 定义

关系除法用于找出与另一个关系中全部元组都有关联的对象。

设：

[
R(X,Y),quad S(Y)
]

则：

[
Rdiv S={xmid orall yin S, (x,y)in R}
]

结果属性为：

[
X=属性(R)-属性(S)
]

## 要点

### 1. 语义是覆盖全部

若：

```text
选课（学号，课程号）
必修课（课程号）
```

则：

[
选课div 必修课
]

表示选修了必修课关系中全部课程的学生。

判断某个学生是否满足：

[
该学生关联的课程集合supseteq 必修课集合
]

### 2. 可以多，但不能缺

某学生除全部必修课外还选了其他课程，仍然满足要求。除法表示“至少覆盖全部”，不是“恰好只有这些”。

### 3. 必须比较具体值

若要求集合为 ({C1,C2,C3})，实际集合为 ({C1,C2,C4})，虽然数量相同，但缺少 C3，仍然不满足。

### 4. 多属性除数按元组整体检查

若：

```text
供应（供应商号，项目号，零件号）
需求（项目号，零件号）
```

则：

[
供应div 需求
]

要求供应商覆盖需求关系中的每一个“项目号＋零件号”组合，不能把两列拆开分别判断。结果属性是供应商号。

3. ((pi_X(R)	imes S)-R)：实际缺失的组合。
4. 对缺失组合投影 (X)：至少缺一项的不合格候选。
5. 全部候选减去不合格候选：覆盖全部要求的合格者。

[

]

### 6. 空除数边界

若 (S) 为空，则没有任何要求需要检查。理论关系代数中，所有在 (pi_X(R)) 中出现的候选都满足条件。

## 易错点

- 把“覆盖全部”误认为“至少匹配一项”。
- 把“至少覆盖全部”误认为实际集合必须与要求集合完全相等。
- 只比较关联数量，不核对具体值。
- 写错结果属性；结果是被除关系去掉除数属性后的剩余属性。
- 多属性除数只检查其中一列，没有按完整元组组合逐项检查。
- 看不懂等价公式中的差集；核心是先构造“应该有”的组合，再找缺项者。
- 认为除数关系为空时结果必为空。

口诀：

> 除法专找“全都要”；结果取剩余列；可以多，不能缺；合格者等于全部候选减去缺项者。

## 真题考法

- 识别“选修全部课程”“完成全部任务”等除法语义。
- 给出关系实例，逐个候选检查是否覆盖全部要求。
- 根据 (属性(R)-属性(S)) 判断结果属性。
- 判断额外关联是否影响结果。
- 判断数量相同但具体值不同是否满足。
- 计算多属性除数，检查全部属性组合。
- 识别除法的基本运算等价表达式。
