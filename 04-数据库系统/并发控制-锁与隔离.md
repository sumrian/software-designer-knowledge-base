# 并发控制：锁与隔离

> 模块：04 数据库系统 ｜ 状态：🟦 学习中/待真题校准

## 定义

并发控制是在多个事务同时执行时，通过锁等机制保证数据一致性，并控制并发异常。

## 要点

### 共享锁与排他锁

- 共享锁 S 用于读取，排他锁 X 用于修改。
- S 与 S 兼容；S 与 X 冲突；X 与 X 冲突。

### 两段锁协议

- 扩展阶段：只能加锁，不能解锁。
- 收缩阶段：只能解锁，不能再加锁。
- 两段锁可保证冲突可串行化；严格两段锁通常将排他锁持有到提交或回滚。

### 死锁

多个事务互相等待对方释放资源，形成循环等待。例如 T1 持有 A 等待 B，T2 持有 B 等待 A。可通过统一加锁顺序、超时或等待图检测处理。

### 隔离异常

- 脏读：读到其他事务尚未提交的数据。
- 不可重复读：同一事务两次读取同一行，值发生变化。
- 幻读：同一查询条件两次读取，结果集新增或减少行。
- 丢失更新：后写入的事务覆盖先写入的结果。

隔离级别通常从读未提交、读已提交、可重复读到串行化逐渐增强，允许的并发异常逐渐减少。

## 易错点

- S 与 S 兼容，涉及 X 时通常冲突。
- 不可重复读关注同一行的值变化；幻读关注查询范围内行集合变化。
- 死锁是循环等待，不是普通锁冲突。
- 两段锁的关键不是固定先读后写，而是进入收缩阶段后不能再次加锁。
- 隔离级别越高，一般并发度越低。

## 真题考法

常给出事务的读写、加锁解锁顺序或两次查询结果，要求判断锁是否冲突、是否违反两段锁、是否死锁，以及属于哪种并发异常。
