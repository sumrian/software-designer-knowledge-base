# 排序：冒泡排序

## 核心
升序冒泡排序比较相邻元素，逆序则交换；一整趟结束后，当前未排序区最大元素到达右端最终位置。

## 性质
- 稳定排序。
- 平均与最坏时间复杂度：O(n^2)。
- 带“本趟无交换则结束”优化时，最好为 O(n)。
- 额外空间：O(1)。
- 最坏比较次数：n(n-1)/2。

## 易错点
- 一次相邻交换不等于一整趟。
- 升序第 1 趟固定的是最大元素，不是最小元素。
- 提前结束条件是某一整趟 0 次交换。
- 若某趟发生过交换，即使趟末序列已经有序，也还需下一趟 0 次交换来确认。
