# 排序：快速排序

> 状态：🟦 基础与真题校准完成，待延迟复测

## 核心思想
选取枢轴 pivot，一趟划分后使 pivot 左侧元素不大于 pivot、右侧元素不小于 pivot，并让 pivot 到达最终位置；随后递归处理左右子序列。

## 一趟划分
- 一趟划分后，pivot 一定处于最终位置。
- 左右子区间内部不要求已经有序。
- 一趟划分时间复杂度为 `O(n)`。
- 本轮重点掌握“挖坑法”：先暂存 pivot；左侧找大于 pivot 的元素填右坑，右侧找小于 pivot 的元素填左坑；左右指针相遇后再把 pivot 放入最终坑位。

## 复杂度与稳定性
- 平均时间复杂度：`O(n log n)`。
- 最坏时间复杂度：`O(n^2)`。
- 平均递归栈空间：`O(log n)`。
- 最坏递归栈空间：`O(n)`。
- 不稳定排序。

## 为什么平均是 O(n log n)
划分较均匀时，递归层数约为 `O(log n)`，而每一层所有子问题合计仍需处理约 `O(n)` 个元素，因此总时间约为 `O(n log n)`。

## 最坏情况直觉
若固定选端点为 pivot，而输入已经有序或近似有序，可能连续划分成 `0 + (n-1)`、`0 + (n-2)` 等极不均匀子问题，从而退化到 `O(n^2)`；递归深度也可能退化到 `O(n)`。

## 本轮校准
- 2020 下半年快速排序划分题：以最后一个元素 4 为 pivot，按题目对应划分方法结果为 `2,3,1,4,7,5,6,8`；单趟划分复杂度为 `O(n)`。
- 已能独立完成一组“挖坑法”划分过程。

## 本轮错因
- 曾把快速排序平均时间复杂度误选为 `O(log n)`；原因是只看到递归层数，漏掉每层合计 `O(n)` 的处理量。
- 曾把平均递归栈空间误选为 `O(n)`；正确为划分均匀时递归深度 `O(log n)`，最坏才退化到 `O(n)`。
