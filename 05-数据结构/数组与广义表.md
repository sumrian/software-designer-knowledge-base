# 数组与广义表

> 模块：05 数据结构 ｜ 状态：🟦 学习中/待真题校准

## 定义

数组是按下标访问、通常连续存储的同类型数据集合；广义表是元素可以是原子或子表的有限序列。

## 要点

- 二维数组行优先存储时，设数组为 (A[L_1..U_1][L_2..U_2])，第二维长度 (N_2=U_2-L_2+1)，元素字长为 (w)，则
  [
  LOC(A[i][j])=base+((i-L_1)N_2+(j-L_2))w
  ]
  先跳过前面的整行，再跳过当前行中的元素。
- 二维数组列优先存储时，设第一维长度 (N_1=U_1-L_1+1)，则
  [
  LOC(A[i][j])=base+((j-L_2)N_1+(i-L_1))w
  ]
  先按列计算偏移。
- 计算地址时必须减去下标下界；题目从 0 开始时下界项恰好为 0，从其他下界开始时不能漏减。
- 稀疏矩阵可用三元组 ((行号,列号,值)) 只保存非零元素，节省空间；需要保留行列坐标以恢复位置。
- 广义表的表头是最外层序列的第一个元素；表尾是去掉表头后剩余的广义表；长度是最外层元素个数，子表内部元素不向外层长度累加。
- 例：(L=(a,(b,c),d))，表头为 (a)，表尾为 (((b,c),d))，长度为 3。

## 易错点

- 行优先与列优先的偏移顺序相反：行优先先乘行号偏移，列优先先乘列号偏移。
- “第几个元素”不能直接代入下标；要先做 (i-L_1)、(j-L_2) 的相对偏移。
- 广义表的表尾仍是一个表，不是单个最后元素；长度只数最外层，不把嵌套表展开。
- 稀疏矩阵的三元组存储不是只保存数值，行号和列号同样不可缺失。

## 真题考法

- 给出数组上下界、存储序、首地址和元素字长，计算指定元素地址。
- 比较行优先/列优先地址公式，判断下标下界变化后的偏移。
- 给出广义表嵌套结构，判断表头、表尾和长度。
- 根据非零元素数量选择普通二维数组或三元组稀疏存储。
