# 顺序查找

> 模块：05 数据结构 ｜ 状态：🟦 基础与外部校准完成，待合格回忆版来源门槛/延迟复测

## 定义
顺序查找（Sequential Search / Linear Search）从线性表的一端开始，逐个将记录关键字与目标关键字比较，直到找到目标或扫描完全部记录。

## 要点
- 不要求表有序；顺序表和链表均可使用逐个比较的思想。
- 长度为 n 时，最坏情况下比较 n 次，时间复杂度为 `O(n)`。
- 各位置等概率且查找成功时：`ASL=(1+2+...+n)/n=(n+1)/2`。
- 普通顺序查找失败时，需要检查全部 n 个元素，比较次数为 n。
- 哨兵法可把目标关键字预置在边界位置，减少循环中的越界/边界条件判断，但不会把 `O(n)` 改为 `O(log n)`。

## 易错点
- 等概率成功 ASL 不是 `n/2`，而是 `(n+1)/2`；因为比较次数序列是 `1,2,...,n`，其平均值为 `(1+n)/2`。
- 哨兵是常数级流程优化，不改变顺序查找的渐进时间复杂度。
