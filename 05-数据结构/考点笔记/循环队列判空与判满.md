# 循环队列判空与判满

- 模块：05 数据结构
- 最小考点：循环队列（牺牲一个存储单元的空/满判定）
- 状态：🟦 原创模拟中发现知识性错误，待按 @study 延迟换题复测；合规回忆版真题校准尚未新增。

## 定义
循环队列使用数组长度 m，front 指向队头元素，rear 指向**下一可入队位置**，牺牲一个数组单元来区别队空与队满。

## 要点
- 队空：`front == rear`
- 队满：`(rear + 1) % m == front`
- 当前队列元素数：`(rear - front + m) % m`
- 最大可容纳元素数：`m - 1`

## 易错点
- `rear == m - 1` 仅表示到达数组最后一个下标，不代表队满；回绕后可继续使用前方空位。
- `(front + 1) % m == rear` 不表示队满；必须根据指针定义判断。
- 如果题目采用不同的 front/rear 定义或额外计数标志，则判空/判满公式可能不同，必须先看约定。

## 原创模拟案例
- 2026-10-19 上午 75题原创模拟第3题：用户选 C（rear == m-1），正确 D（(rear+1)%m==front），得 0/1。
- 反例：m=5，front=2，rear=4，此时 rear==m-1 但仍可再入队一个元素，未满。

给定数组长度、front/rear 的含义、是否牺牲一个单元，通过具体位置判断空/满或求队列长度；本轮为原创题，不计合规回忆版真题。
