# Java 字符串比较：`==` 与 `equals()`

> 模块：07 程序设计语言 ｜ 状态：🟦 已整理，待延迟复测与后续真题校准

## 定义
- 对引用类型，`==` 判断两个引用是否指向同一个对象（引用身份）；对基本类型，`==` 比较数值。
- `String.equals()` 比较字符串内容，且区分大小写。

## 要点与案例
```java
String a = new String("soft");
String b = new String("soft");
System.out.println((a == b) + " " + a.equals(b));
```
输出：`false true`。两次 `new String` 创建不同对象，因此引用身份不同；两个对象的字符内容相同，因此 `equals()` 返回 true。

## 易错点
- 不要把 `==` 和 `equals()` 的含义对调。
- 也不要推断“内容相同的字符串使用 `==` 必定为 false”：字符串字面量可能因常量池而共享对象，需结合对象创建方式判断。
- `equals()` 对字符串内容进行区分大小写的比较；例如 `"soft".equals("Soft")` 为 false。

## 真题考法
给出 `new String(...)`、字符串字面量或混合赋值代码，区分引用身份、常量池与内容相等，并判断输出。
