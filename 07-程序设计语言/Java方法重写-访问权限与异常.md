# Java 方法重写：访问权限与受检异常

## 定义
方法重写（overriding）发生在子类重新提供继承自父类的实例方法实现时。重写必须遵守可替换性与 Java 语言的签名、返回类型、访问权限和异常约束。

## 要点
- 重写方法的访问权限不能比父类方法更严格；父类为 public，子类不能降为 protected 或包访问权限。
- 返回类型可以相同；引用类型返回值允许协变，即子类返回类型可以是父类返回类型的子类型。例如父类返回 Number，子类可返回 Integer。
- 重写方法可以不声明受检异常，也可以声明父类已允许的受检异常的子类型；不能新增更宽泛的受检异常。
- FileNotFoundException 是 IOException 的子类。因此父类方法声明 throws IOException 时，子类重写为 throws FileNotFoundException 在异常范围上合法。
- 重载（overloading）是同名但参数列表不同；不要与重写混淆。

## 易错点
- 把“异常类型变了”一律判错：要比较异常的继承层级，子类重写只能收窄受检异常范围。
- 只检查异常列表，忘记访问权限约束。即使异常合法，降低 public 方法的可见性仍会编译失败。
- 协变返回类型是返回类型的特殊规则，不等于允许任意不兼容的返回类型。
