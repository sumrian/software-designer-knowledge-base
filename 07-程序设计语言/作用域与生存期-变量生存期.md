# 变量生存期

> 模块：07 程序设计语言 ｜ 状态：🟦 待真题校准

## 定义
作用域描述名字在哪些程序位置可见；生存期描述变量对应的存储对象在程序运行期间从何时存在到何时结束。二者不是同一概念。

## 要点
- 普通局部变量的典型实例随一次函数/块执行创建和结束。
- 静态局部变量的名字仍是局部作用域，但存储对象通常贯穿整个程序运行期，因此跨调用保留状态。
- 全局/静态存储期对象通常具有整个程序运行期的生存期。
- 指针/引用变量的生存期与它所指对象的生存期可以不同。
- C 中局部指针离开作用域并不会自动 free 它指向的动态分配内存。

## 易错点
- 离开作用域不等于对象一定立即结束生存期。
- static 局部变量不是全局可见变量。
- 普通局部变量每次调用通常是新的实例；静态局部变量跨调用保留。

## 真题考法
- 连续调用含 static 局部变量的函数，计算输出。
- 比较 static 局部变量与普通局部变量。
- 作用域与生存期概念辨析。
- 指针变量与堆对象生存期辨析。
