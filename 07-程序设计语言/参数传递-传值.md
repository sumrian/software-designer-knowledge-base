# 参数传递—传值

> 模块：07 程序设计语言 ｜ 状态：🟦 待真题校准

## 定义
传值（Call by Value）是在调用时把实参当前的值复制给形参。形参与实参是不同变量，修改形参本身不会改变调用者中的实参。

## 要点
- 实参提供值，形参获得该值的副本。
- 修改普通形参只改变副本，不改变实参。
- 表达式作为实参时，先计算表达式，再把结果值复制给形参。
- 纯传值下，在函数内部交换两个形参不会交换调用者的两个实参。
- Java 参数传递也是传值；对象参数复制的是“引用值”。两个引用副本可指向同一对象，因此通过形参修改对象内容可被外部观察到。
- Java 中给形参重新赋一个新对象，只改变形参保存的引用值，不会改变调用者引用变量的指向。

## 易错点
- “值相同”不代表形参与实参是同一个变量。
- “传值”不等于“函数无法产生任何外部可见影响”；若值本身是指针/引用，可通过其访问并修改共享对象。
- 要区分“修改引用指向的对象”和“修改形参引用本身”。
