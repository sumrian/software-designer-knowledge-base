# 参数传递—传址

> 模块：07 程序设计语言 ｜ 状态：🟦 待真题校准

## 定义
传址强调被调用过程能够通过实参的地址/引用访问调用者中的原对象，因此通过地址修改所指内容会直接影响实参。

## 要点
- 传值复制值；传址模型通过地址定位原对象。
- C 中常通过传递指针值实现间接修改调用者对象；C++ 可使用引用参数。
- `*p = value` 修改指针所指对象；`p = newAddress` 只修改局部指针变量本身（若指针参数本身按值传递）。
- 传址/引用机制可实现对调用者变量的 swap。
- 连续语句要使用前一语句已经修改后的实参值。
- Java 对象参数仍是传值，不能因为对象内容可被修改就称 Java 为“传址”。

## 易错点
- C 代码中 `*` 既可作解引用运算符，也可作乘法运算符，必须结合位置读取。例如 `*x = *x * 2` 是 `(*x) = (*x) × 2`。
- 修改指针本身与通过指针修改对象不是一回事。
- 逐句执行时不能继续使用修改前的旧值，除非旧值已提前保存到临时变量。

## 真题考法
- 传值与传址结果对比。
- 指针/引用 swap。
- 多个指针参数连续修改后的变量值。
- 判断修改的是指针变量还是指向对象。
