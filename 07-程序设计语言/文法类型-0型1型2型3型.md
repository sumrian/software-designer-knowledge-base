# 文法类型—0 型 / 1 型 / 2 型 / 3 型

> 模块：07 程序设计语言 ｜ 状态：🟦 待真题校准

## 定义
Chomsky 文法体系按产生式限制程度分为 0 型、1 型、2 型和 3 型。编号越大，产生式限制越严格，能描述的语言范围越小。

## 要点
- 0 型：无限制文法，限制最少，表达能力最强。
- 1 型：上下文有关文法，典型规则具有上下文约束，并通常满足非收缩特征。
- 2 型：上下文无关文法（CFG），每条产生式左边必须是单个非终结符，即 `A → α`。
- 3 型：正规文法，在 2 型基础上进一步满足线性形式；典型右线性为 `A → aB` 或 `A → a`。
- 包含关系：`3 型 ⊂ 2 型 ⊂ 1 型 ⊂ 0 型`。
- 程序语言的语法结构常用上下文无关文法描述；正规语言与后续正规式、有限自动机关系密切。

## 易错点
- 2 型限制重点在产生式左边必须是单个非终结符，不是限制右边只能出现一个非终结符。
- 左边是单个非终结符只能保证满足 2 型基本形式；要判断为 3 型，还必须继续检查右边是否满足线性限制。
- `AB → a` 不符合 2 型，因为左边不是单个非终结符。
- 包含方向不能记反：编号越大，限制越严格。

## 真题考法
- 根据产生式判断文法类型，尤其区分 2 型和 3 型。
- 判断上下文无关文法产生式的形式约束。
- 判断正规文法的右线性/左线性形式。
- 判断四类文法包含关系。
- 本轮基础题组 4/5；首次把“满足 2 型基本条件”误判为 3 型，随后针对性补强 2/2；外部校准 2/2。
