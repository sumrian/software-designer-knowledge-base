# 编译与解释

状态：🟦 基础与校准完成，待延迟复测。

## 核心区别
- 编译：通常先把高级语言源程序整体翻译成目标程序/目标模块，再执行；前期需要编译，后续反复执行通常更快。
- 解释：典型模型下在运行过程中分析源程序并执行相应操作，通常不先生成独立完整的目标程序。
- 编译程序和解释程序都属于语言处理程序。

## 语言处理与运行流程
- 高级语言源程序 → 编译程序 → 目标程序/目标模块。
- 汇编语言源程序 → 汇编程序 → 机器语言目标程序。
- 多个目标模块 + 库 → 链接程序 → 可执行程序；链接阶段处理模块间外部符号引用。
- 可执行程序 → 装入程序 → 内存，准备执行。

## 基本对比
- 反复运行且源代码基本不变：编译后运行通常效率更高。
- 同一高级语言源程序跨不同平台采用编译方式时，通常需使用对应平台编译器重新编译；一个平台的机器代码不保证能直接在其他平台运行。
- 具体语言实现可能混合编译、字节码、解释/JIT 等机制；软考基础题按典型编译/解释模型判断。
