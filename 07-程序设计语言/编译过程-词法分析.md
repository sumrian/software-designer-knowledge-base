# 编译过程：词法分析

## 定义
词法分析（Lexical Analysis）是编译过程的前端阶段之一，负责扫描源程序字符流，将连续字符识别为有意义的单词符号（Token）。核心转换：`字符流 → Token 流`。

## 要点
- 常见 Token：关键字、标识符、常量、运算符、界符。
- 空格、换行、注释通常用于分隔或辅助扫描，不作为普通 Token 继续传递。
- 词法分析关注“一个单词/符号本身是否合法”，而不是多个 Token 组合后的程序结构是否合法。
- 对存在前缀关系的运算符（如 `>` 与 `>=`），扫描时应识别完整合法 Token，常体现最长匹配思想。

### 例子
源程序：`int total = count + 10;`

可识别为：`int`（关键字）、`total`（标识符）、`=`（运算符）、`count`（标识符）、`+`（运算符）、`10`（常量）、`;`（界符）。

若语言规定标识符必须以字母开头，则 `2count` 不能作为合法标识符识别，属于词法层面的非法单词。

## 易错点
- Token 本身非法（如出现语言不允许的字符）→ 词法问题。
- 每个 Token 都合法，但排列/结构不符合程序规则 → 不是词法分析负责判断的问题。
- 词法分析不是简单按空格切字符串；例如合法运算符 `>=` 应整体识别，而不是拆成 `>` 和 `=`。

## 真题考法
常见题眼：识别单词、识别 Token、识别关键字/标识符/常量、扫描源程序字符、字符序列转换为单词符号序列。
