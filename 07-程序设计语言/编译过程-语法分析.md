# 编译过程—语法分析

> 模块：07 程序设计语言 ｜ 状态：🟦 待真题校准

## 定义
语法分析以词法分析产生的 Token 序列为输入，根据程序设计语言的文法规则判断 Token 的组合结构是否合法，并建立相应的句法结构。

## 要点
- 核心链路：`Token 序列 → 语法分析 → 按文法检查结构 → 句法结构`。
- 词法分析负责“认单词”，语法分析负责“看句型”。
- 若每个 Token 本身都合法，但组合顺序无法匹配文法规则，属于语法错误。
- 语法分析可依据文法建立分析树/语法树等句法结构。

## 易错点
- 不要把“已经获得合法 Token 后检查文法结构”误判为词法分析。本轮基础题第 1 题出现该混淆，随后 2 道针对性变式均答对。
- 非法字符或 Token 本身无法识别属于词法问题；Token 都合法但缺括号、顺序不符合句型等属于语法问题。
- 语法分析不负责确认变量是否声明、类型是否匹配等超出句法结构的问题。

## 真题考法
- 高频职责辨析：根据文法分析单词符号序列、判断程序语句结构是否合法、建立句法结构 → 语法分析。
