# ISO 9000

> 状态：🟦 待真题校准

## 定义
ISO 9000 系列是一族质量管理体系相关标准，关注组织建立和运行规范的质量管理体系。

## 要点
- ISO 9000：质量管理体系基础与术语。
- ISO 9001：质量管理体系要求，可作为质量管理体系认证依据。
- ISO 9000 系列关注质量管理体系；CMM/CMMI 更关注软件过程能力与成熟度。

## 易错点
- ISO 9000 与 ISO 9001 作用不要反：9000=基础/术语，9001=要求/认证。
- 通过 ISO 9001 质量管理体系认证，不代表每个具体产品零缺陷。

## 真题考法
常考 ISO 9000/9001 作用辨析、认证含义，以及与 CMM/CMMI 的区别。
