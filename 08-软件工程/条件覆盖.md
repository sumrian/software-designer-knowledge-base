# 条件覆盖

> 模块：08 软件工程 ｜ 状态：🟦 待真题校准

## 定义
条件覆盖要求复合判定中的每个基本条件都至少取一次 True 和一次 False。

## 要点
- 先把复合判定拆成基本条件，再逐个检查 T/F。
- 条件覆盖关注基本条件自身，不要求完整判定一定 T/F 都出现。
- 条件覆盖不要求所有条件组合都出现；后者属于更强的条件组合覆盖。
- 条件覆盖与判定覆盖互不必然包含。

## 与判定覆盖的区别
- 判定覆盖：看整个表达式的 T/F。
- 条件覆盖：看表达式内每个基本条件自己的 T/F。
- 对 A&&B 使用 TF、FT：条件覆盖满足，但完整判定始终 F，判定覆盖不满足。
- 对 A||B 使用 TF、FT：条件覆盖满足，但完整判定始终 T，判定覆盖不满足。
- 使用 TT、FF 时，对 A&&B 可同时满足条件覆盖和判定覆盖。

## 易错点
- 不要把完整判定的 T/F 当作基本条件覆盖情况。
- 条件覆盖不等于条件组合覆盖。
- 不要认为条件覆盖天然强于判定覆盖；两者关注目标不同。
- Java 存在短路求值，但基础题通常按题目给出的各基本条件逻辑取值判断。
