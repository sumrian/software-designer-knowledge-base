# UML 类图：关联多重度

## 定义
关联多重度描述关联一端的一个对象能够对应另一端多少个对象，数字标在被计数的另一端。

## 要点
- 1：恰好一个。
- 0..1：零或一个。
- * 或 0..*：零到多个。
- 1..*：至少一个。
- 2..5：两个到五个。
- 例：User 端标 1，Order 端标 0..*，表示每个 Order 恰好一个 User，每个 User 可有零到多个 Order。
- Java 集合或引用声明本身不能保证 UML 数量下限或非空，需要业务校验。

## 易错点
- 多重度写在被计数对象的一端，而不是被固定对象的一端。
- 星号可以为零；0..1 可以不存在。
- 多重度用于关联约束，不直接用于泛化关系。
