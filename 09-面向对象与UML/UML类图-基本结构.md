## 定义
类图（Class Diagram）是 UML 中最基础、最常用的**静态结构图（Structural Diagram）**，描述系统中类的内部组成（类名、属性、操作）及类与类之间的静态关系。

## 三分格结构（Three-Compartment Box）

```
┌──────────────────────────┐
│    顶层：类名（必须）     │
├──────────────────────────┤
│    中层：属性列表（可省） │
├──────────────────────────┤
│    底层：操作列表（可省） │
└──────────────────────────┘
```

- **类名格**是唯一不可缺少的部分；属性栏与操作栏可根据视图需要折叠/省略。
- 属性格式：`[可见性] 属性名 [: 类型] [= 初始值]`
- 操作格式：`[可见性] 方法名([参数列表]) [: 返回类型]`

## 核心标记速查

| 视觉特征 | 含义 | Java 对应 | 口诀 |
|---|---|---|---|
| **斜体（*Italics*）类名** | 抽象类 | `abstract class` | 斜体抽 |
| **斜体（*Italics*）方法名** | 抽象方法 | `abstract void foo();` | 斜体抽 |
| **下划线（<u>Underline</u>）属性/方法** | 静态成员（类级别） | `static` | 下线静 |
| `<<interface>>` 构造型 | 接口 | `interface` | — |

### 交叉组合

| 组合 | UML 表现 | Java 对应 |
|---|---|---|
| 实例 + 具体 | 正体、无下划线 | `void draw() {}` |
| 实例 + 抽象 | 斜体、无下划线 | `abstract void draw();` |
| 静态 + 具体 | 正体、下划线 | `static int getCount() {}` |
| 静态 + 抽象 | ⚠️ Java 中不合法 | — |

## 类图 vs 对象图

| | 类图 | 对象图 |
|---|---|---|
| 表示 | 类（模板） | 对象（实例快照） |
| 名称格式 | `ClassName`（不带下划线） | `objName : ClassName`（**带下划线**） |
| 匿名形式 | — | `: ClassName`（带下划线） |

## UML 图分类归属

| 静态结构图 | 动态行为图 |
|---|---|
| **类图**、对象图、构件图（组件图）、部署图、包图、组合结构图 | 用例图、活动图、状态机图、序列图、通信图等交互图 |

## 易错点
1. 下划线 ≠ 私有；下划线 = 静态。私有用 `-` 表示。
2. 斜体 ≠ 静态；斜体 = 抽象。
3. 对象图中对象名带下划线，类图中类名不带——不要与静态的下划线混淆，它们作用于不同层级。
4. 属性栏和操作栏可省略，类名栏不可省略。
