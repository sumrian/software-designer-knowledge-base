# 多态与动态绑定

- 模块：09 面向对象与 UML
- 阶段：🟦 原创模拟单题答对，仍待正式教学/延迟复测与合规回忆版真题校准。

## 核心结论

Java 中，父类引用可以指向子类对象。调用被子类重写的实例方法时，通常根据对象的运行时实际类型进行动态分派，执行相应的重写实现。

## 示例

```java
class Animal {
    void speak() { System.out.println("animal"); }
}
class Dog extends Animal {
    @Override
    void speak() { System.out.println("dog"); }
}
Animal x = new Dog();
x.speak(); // 输出 dog
```

引用变量的声明类型影响编译期可访问的成员和类型检查；实际执行哪个被重写的实例方法，通常由运行时对象类型决定。静态方法不按这种方式进行实例方法动态分派。

## 易错点

不要把“编译期引用类型决定可访问性”与“运行时对象类型决定重写实例方法的动态分派”混为一谈。
