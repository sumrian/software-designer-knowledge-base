# 序列图 loop 与条件约束

## 定义
loop 组合片段表示按照守卫条件及次数约束重复执行框内整个交互过程，通常对应 Java for、while。

## 要点
- loop 内可以有多条消息及返回消息，重复的是整个片段。
- 守卫 [condition] 控制下一轮是否继续；状态变化会改变条件结果。
- loop(1,5) 表示允许一至五次，并非固定五次；允许零次的 loop 可表示空集合场景。
- while 可能零次执行，实际次数不一定达到最大次数。
- 循环退出可能是失败或次数耗尽，不代表业务成功。
- 正常执行路径中的公共后续消息放在 loop 框外。

## Java/UML 案例
```java
int i = 0;
boolean success = true;
while (i < items.size() && success) {
    success = inventoryService.reserve(items.get(i));
    i++;
}
auditService.recordResult(success);
```
守卫 [i < items.size() && success]；若四个订单项的预留结果依次 true、true、false，则执行三轮，第四项不处理，之后记录 false。若 items 为空则循环零次，仍记录结果。

## 易错点
- 把 loop 当成单次 opt、互斥 alt 或并行。
- 将最大迭代次数误认为实际执行次数。
- 忽略初始条件为假、提前成功或失败。
- 将公共消息放入循环体。
- 在题目未给出调用结果时推断具体循环次数。
