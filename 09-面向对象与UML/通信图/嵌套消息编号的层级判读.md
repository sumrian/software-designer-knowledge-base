# 嵌套消息编号的层级判读

## 定义
UML 通信图以点号分隔的消息编号表示先后顺序与嵌套调用关系。

## 要点与完整案例
顶层 1 与 2 同级；1.1 与 1.2 同级；1.2.1 与 1.2.2 同级。直接父级为去掉最后一个编号段的前缀。

Java 调用案例：execute() 依次调用 submitOrder()（1）、notifyUser()（2）；submitOrder() 内调用 validateOrder()（1.1）、saveOrder()（1.2）；saveOrder() 内调用 writeDatabase()（1.2.1）、updateCache()（1.2.2）。

## 易错点
