## 定义
通信图消息标记 `1: *[库存充足] processItem()` 同时表达消息迭代特征（`*`）与守卫条件（`[库存充足]`）。

## 要点与完整案例
购物车逐项处理：
```java
for (Item item : cartItems) {
    if (inventory.hasStock(item)) {
        inventory.processItem(item);
    }
}
```
通信图可抽象标为 `1: *[库存充足] processItem()`。循环不保证一定发送一次；条件不成立时相应消息可不发送。是否以及何时重新求值要依据具体业务控制流，不能单凭标记认定条件仅在首次执行时检查。

## 易错点
1. `*` 不表示无条件执行，也不保证恰好一次或至少一次。
2. `[条件]` 是守卫而非注释；某次成立不意味着后续迭代永久放行。
3. “不正确的是”需找错误陈述，不可把正确描述选出。
4. 未标 `*` 不等于没有守卫条件；例如 `2: [支付成功] sendReceipt()`。

## 真题考法
识别通信图中的条件消息、迭代消息及组合标记；将业务循环加条件判断映射为 `*[条件]`；对“正确/不正确”陈述作辨析。以上均为自编练习总结，不冒充已核验历年真题。合规回忆版真题：0/2，待校准。
