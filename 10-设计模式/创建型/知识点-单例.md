## 定义
限制实例化并提供全局访问点；饿汉式通过类初始化创建，普通懒汉式需考虑线程安全。

## 要点
私有构造、静态实例、统一入口 getInstance()；注意 JVM 类加载器作用域，不等于分布式唯一。

## Java / 场景示例
Java：private static final Config INSTANCE=new Config(); private Config(){} static Config getInstance(){return INSTANCE;}

## 易错点
不要把只有 static 方法的类都判断为单例。
