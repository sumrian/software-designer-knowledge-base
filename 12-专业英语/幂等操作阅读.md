# 专业英语阅读：幂等操作与重试安全

## 原文核心

An idempotent operation has the same intended effect whether it is performed once or several times. A client may retry a request after a timeout because it cannot know whether the server completed the first attempt. Retrying an idempotent request is generally safer, while a non-idempotent operation may create duplicate effects unless the application adds a deduplication mechanism.

## 要点与词组

- **idempotent operation**：幂等操作；执行一次或多次，预期效果相同。
- **intended effect**：预期效果。
- **retry a request after a timeout**：在请求超时后重试。
- **duplicate effects**：重复的业务效果。
- **deduplication mechanism**：去重机制。
- 幂等性关注重复执行的业务效果，不保证网络不会超时，不保证响应更快，也不意味着所有 HTTP POST 请求都幂等。
