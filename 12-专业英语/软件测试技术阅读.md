# 专业英语：软件测试技术阅读

## 原文与考点

Unit tests check a small component in isolation, often with dependencies replaced by mocks. Integration tests examine whether multiple components work together and exchange data correctly.

- **unit test**：单元测试，检查较小组件，通常尽量隔离其依赖。
- **in isolation**：在隔离条件下、单独测试。
- **dependency**：依赖项。
- **mock**：模拟对象，用于替代依赖以便测试；不能据此证明真实外部服务一定正常。
- **integration test**：集成测试，检查多个组件协同工作以及数据交换是否正确。
- **work together / exchange data**：协同工作／交换数据，是识别集成测试目标的直接线索。
