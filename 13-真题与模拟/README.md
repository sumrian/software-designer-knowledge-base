# 真题与模拟

> 真题是核心。上午在 `上午综合/`，下午在 `下午设计/`。
> 文件命名：`YYYY年上半年-上午.md` 等。

## 真题索引

已核验题目的年份、场次、题号、来源和转述版统一记入 [真题索引](./真题索引.md)。只有元数据和来源已核验的题目才能进索引；无法核验时标为仿真题。

## 使用方式

- 考点学习当天就做对应历年真题，不等到冲刺阶段。
- 每两周组一次跨章节上午题；每周至少一次下午专项。
- 2026-09-14 起开始整套计时模考；作答时长和批次以当年准考证与机考系统说明为准，不沿用旧纸笔考试时长。
- 错题立即进 [错题本](../14-错题本)并排入间隔复习。
- 每套完成后在此登记成绩、用时和错点。
