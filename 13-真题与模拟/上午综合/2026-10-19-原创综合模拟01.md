A. 依赖关系（Dependency）
B. 聚合关系（Aggregation，空心菱形）
C. 组合关系（Composition，实心菱形）
D. 泛化关系（Generalization）

### 第3题 · 数据结构与算法 · 循环队列

A. front == rear
B. (front + 1) % m == rear
C. rear == m - 1
D. (rear + 1) % m == front

### 第4题 · 程序设计语言 · Java 参数传递
阅读以下 Java 程序，运行结果为（ ）。
```java
public class Main {
    static void update(int x, int[] data) {
        x = 99;
        data[0] = x;
    }

    public static void main(String[] args) {
        int x = 5;
        int[] data = {2};
        update(x, data);
        System.out.println(x + " " + data[0]);
    }
}
```

A. 5 2
B. 5 99
C. 99 2
D. 99 99

### 第6题 · 操作系统 · PV 同步

A. `P(mutex); P(empty); put(); V(mutex); V(full);`

C. `P(full); P(mutex); put(); V(mutex); V(empty);`
D. `P(empty); P(mutex); put(); V(mutex); V(empty);`
