```java
public class Main {
    static void update(int x, int[] data) {
        x = 99;
        data[0] = x;
    }

    public static void main(String[] args) {
        int x = 5;
        int[] data = {2};
        update(x, data);
        System.out.println(x + " " + data[0]);
    }
}
```

B. 5 99
C. 99 2
D. 99 99
