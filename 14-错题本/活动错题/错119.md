# 错119 · 继承的一般概念与语言限制

- 模块：09 面向对象与 UML
- 考点：继承
- 首次错误日期：2026-10-05
- 状态：🟨 D+1 延迟换题通过 1/2
- 原错因：把具体语言的单继承限制误当成面向对象继承的一般定义。
- 正确判据：继承概念本身不规定只能单继承；是否支持多重继承由具体语言决定。例如 Java 类只支持单继承，C++ 支持多重继承。
