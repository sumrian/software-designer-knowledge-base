# 错126：关联多重度两端标注方向

- 模块：09 面向对象与 UML
- 考点：类图：关联多重度
- 首次错误：2026-10-08，基础验收第 2/5 题，选择 A，正确 B。
- 情境：Reader 与 Book，单本 Book 对应 0..1 名 Reader，单名 Reader 对应 1..* 本 Book。
- 错因：把两端标注反向；误将对象自身对应数量写在自身端。
- 正确判据：固定一端的一个对象，数另一端的对象数，将数量标注在另一端。Reader 端 0..1，Book 端 1..*。
