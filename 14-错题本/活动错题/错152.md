## 原始错题与作答
代码：
```java
String a = new String("soft");
String b = new String("soft");
System.out.println((a == b) + " " + a.equals(b));
```
用户选择 C：`true false`；正确答案 B：`false true`。

## 错因
把引用比较 `==` 与字符串内容比较 `equals()` 的语义混淆，并把二者的结果颠倒。

## 正确判据
- 对引用类型，`==` 判断两个引用是否指向同一个对象；对基本类型，`==` 比较数值。
- `String.equals()` 比较字符串内容（区分大小写）。
- 两次 `new String("soft")` 创建两个不同的 String 对象，因此 `a == b` 为 `false`；内容相同，因此 `a.equals(b)` 为 `true`。
- 不要误推成“相同字面量变量用 == 一定为 false”：字符串字面量可能因常量池而共享对象；应按具体对象创建方式判断。
