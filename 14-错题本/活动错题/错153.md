## 原始错题与作答
题目要求为设备向内存连续传送大量数据，降低 CPU 逐字节搬运负担。用户选择 D：高速缓存预取；正确答案 C：DMA 方式。

## 错因
将 CPU/存储层次中的高速缓存预取优化，与设备和主存之间的 I/O 数据传送机制混为一谈；误以为缓存预取可以取代 I/O 控制器。

## 正确判据
- DMA 控制器（DMAC）负责设备与主存之间的数据块传送，数据路径不需要 CPU 逐字节搬运。
- CPU 通常负责初始化 DMA 传输，并在传输完成时处理通知；DMA 适合大批量数据。
- 程序查询需要 CPU 反复查询；中断方式会在设备事件/传送完成时让 CPU 处理；通道则是更专用的 I/O 处理器机制。
- 高速缓存预取是为减少处理器访问存储器延迟的缓存优化，不是 I/O 控制方式，不能替代 DMA 控制器。
