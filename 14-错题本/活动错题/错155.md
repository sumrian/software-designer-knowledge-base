## 原始错题与作答
原文指出，unit tests 检查隔离的小组件，常以 mocks 替代依赖；integration tests 检查多个组件是否协同工作并正确交换数据。用户选择 A（单元测试主要用于高负载性能测量）；正确答案 B（集成测试关注组件间交互）。

## 错因
阅读时没有抓住原文对 unit tests 与 integration tests 的对照，选项 A 将性能/负载测试的目标错误套用到单元测试上。

## 正确判据
- unit test：隔离测试一个较小组件；mock 可替代依赖，便于独立验证。
- integration test：验证多个组件之间的协作和数据交换。
- mock 不证明真实外部服务一定正常；单元测试也可以覆盖错误处理。
