# 错101：排序横向稳定性与空间复杂度

- 日期：2026-09-16
- 分类：数据结构 / 排序 / 横向综合
- 状态：🟦 当场补强通过，待延迟复测

## 本轮暴露
- 稳定性综合中把直接选择混入稳定组；随后又把直接插入混入不稳定组。
- 综合性质题把堆排序误判为稳定。
- 空间综合中把希尔、直接选择、堆等原地算法误写为 O(n)，并再次把快排平均递归栈空间误写为 O(n)。
- 算法识别中把“稳定 + O(n log n) + O(n) 辅助空间 + 合并有序子序列”误识别为希尔，正确为归并。

## 正确分类
稳定：直接插入、冒泡、归并。
不稳定：直接选择、希尔、快速、堆。
典型额外空间：直接选择 O(1)、希尔 O(1)、堆 O(1)、归并 O(n)、快速平均递归栈 O(log n)（最坏 O(n)）。
