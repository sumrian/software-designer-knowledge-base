# 错33 · SPOOLing 输入进程与输出进程职责

- 状态：🟦 新错题
- 日期：2026-08-14
- 出处：自适应题组（设备与作业：SPOOLing 输入/输出过程与常见考法，第 4 题）
- 题干（简）：输入设备产生数据，系统采用 SPOOLing，判断由哪个专门进程负责把输入设备的数据送入输入井。
- 我的答案：D（输出进程负责把输入设备的数据写入输入井）
- 正确答案：B（输入进程先把数据从输入设备送入输入井，用户作业随后再使用这些数据）
- 错因：把“输入/输出”按用户作业视角混成一个概念，没有用数据流方向判断专门进程职责；输入设备到输入井这一段必须由输入进程负责，输出进程只负责输出井到输出设备。
- 纠正规则：输入链路=`输入设备 → 输入进程 → 输入井 → 用户作业`；输出链路=`用户作业 → 输出井 → 输出进程 → 输出设备`。判断专门进程时，先看数据正在“进系统”还是“出系统”。
- 关联知识点：操作系统 / 设备与作业：SPOOLing 输入/输出过程与常见考法
