# [#错36] IP 数据报 · TTL 归零与丢弃

- 出处：自适应题组（2026-08-17）
- 题干（简）：IPv4 数据报经过路由器后 TTL 从 2 减为 1；下一跳路由器继续转发时，TTL 减到 0 后应如何处理？
- 我的答案：A（TTL 变成 0 后仍正常转发）
- 正确答案：B（TTL 变成 0 后，路由器应丢弃该数据报）
- 错因：把 TTL 仅理解为会递减的计数字段，没有把“TTL 归零即停止转发/丢弃”这一边界条件一起记住。
- 纠正规则：路由器转发 IPv4 数据报时先使 TTL 减 1；若结果为 0，则丢弃该数据报，不再继续转发。TTL 的核心作用是限制数据报可经过的路由跳数，防止路由环路导致无限转发。
- 关联知识点：计算机网络 / 网络层 / IP 数据报与基本转发
