# #错38 · TCP/UDP 消息边界

- 日期：2026-08-17
- 模块：03 计算机网络
- 子考点：传输层：TCP 与 UDP 特性及适用场景
- 出处：自适应题组第 3 题
- 题干（简）：应用连续两次发送 `ABC`、`DEF`，判断 TCP/UDP 是否保留应用层消息边界。
- 我的答案：B；理由中写“UDP 是数据报格式，TCP 才是字节流有边界”。
- 正确答案：C。
- 正确结论：TCP 面向字节流，不保证保留应用层每次 send 的消息边界；UDP 面向数据报，保留数据报边界。
- 错因：知道“TCP=字节流、UDP=数据报”，但把“字节流”和“有消息边界”的关系理解反了。
- 错因类型：概念/应用
- 当场动作：基础 5 题完成后追加 2 道针对性变式，重点验证“字节流无应用消息边界、数据报保留边界”。
