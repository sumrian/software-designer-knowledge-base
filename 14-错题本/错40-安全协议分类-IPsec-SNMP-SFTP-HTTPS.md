# #错40 · 安全协议分类：IPsec / SNMP / SFTP / HTTPS

- 状态：✅ 已归档
- 日期：2026-08-18
- 模块：03 计算机网络
- 子考点：应用层：HTTP/HTTPS（真题校准扩展到安全协议分类）
- 出处：2023 年下半年软件设计师综合知识第 14 题（考友回忆版）
- 题干（简）：下列协议中，不属于安全协议的是：A. IPsec / B. SNMP / C. SFTP / D. HTTPS。
- 我的答案：A（IPsec）
- 正确答案：B（SNMP）
- 错因：把 IPsec 与普通网络管理协议混淆，没有按“协议的主要用途”做分类。
- 纠正规则：IPsec 用于保护 IP 通信；SFTP 用于安全文件传输；HTTPS 为 HTTP over TLS；SNMP 的主要用途是网络管理，软考常规分类下不归入安全协议。
- 易错补充：SNMPv3 自身包含安全机制，但本题按协议主要用途分类，考的是 SNMP=网络管理协议。
