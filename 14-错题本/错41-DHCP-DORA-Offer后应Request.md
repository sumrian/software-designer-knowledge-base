# #错41 · DHCP DORA：Offer 后应为 Request

- 日期：2026-08-18
- 模块：03 计算机网络
- 子考点：应用层：DHCP
- 出处：模拟校准题
- 题干（简）：DHCP 的 DORA 流程中，客户端在收到服务器的 Offer 后，下一步通常发送什么？
- 我的答案：D（DNS Query）
- 正确答案：B（DHCP Request）
- 错因：DORA 四步顺序未形成稳定映射，把 DHCP 流程与 DNS 查询混入同一序列。
- 纠正规则：`Discover → Offer → Request → ACK`；客户端发现服务器后收到 Offer，再发送 Request 选择/请求租约，最后由服务器 ACK 确认。
- 记忆：发现 → 提供 → 请求 → 确认。
- 错因类型：流程顺序
