# 错96：冒泡排序逐趟与提前结束

日期：2026-09-14
状态：🟦 当场补强通过，待延迟复测

## 错因
1. 曾把一次相邻交换当成完整一趟冒泡。
2. 曾误判升序第 1 趟固定的是最小元素；正确应为最大元素。
3. 真题两趟过程题曾漏掉最开始的一对相邻元素比较。
4. 曾误认为某趟结束后序列已经有序就可立即停止；优化版应以“某一整趟 0 次交换”为提前结束条件。

## 纠正
- 升序冒泡每完成一趟，当前未排序区最大元素到达右端最终位置。
- 一趟必须连续扫描到当前未排序区末端。
- 某趟发生过交换，即使趟末已排序，也还需下一趟 0 次交换来确认。

## 复测
安排后续换题延迟复测；同日补强不计延迟复测通过。
