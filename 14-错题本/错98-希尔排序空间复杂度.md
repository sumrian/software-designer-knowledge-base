# 错98：希尔排序空间复杂度

- 日期：2026-09-14
- 分类：数据结构 / 排序 / 希尔排序
- 状态：🟦 当场补强通过，待延迟复测
- 首错：把希尔排序额外空间选成 O(n)。
- 二次暴露：在 d=3 的变式中选 O(3)，未按渐进复杂度把固定常数归为 O(1)。
- 正确结论：希尔排序通常原地进行分组插入，只使用固定数量临时变量，因此额外空间为 O(1)。逻辑上的 d 组不代表建立 d 个数组；任何固定常数空间在渐进表示中均为 O(1)。
